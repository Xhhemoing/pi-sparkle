## Request and disposition

The request is to remove all first-party SHA-256 mechanisms and runtime integrity checks. The user explicitly accepted removal and delegated implementation to Luna. No replacement cryptographic hash is selected: opaque random versioned locators are used where an ID is needed; exact bytes are compared for equality/dedupe where needed, with no cryptographic tamper guarantee. Legacy records are never silently reclassified.

This report records the dependency-independent `migrate-legacy` slice only. It replaces digest-based equality/copy checks with direct byte comparison while preserving dry-run, copy-not-overwrite, corrupt-log refusal, and atomic publication semantics. Persisted wire schemas are unchanged. Migration execution, live-provider runs, production apply/rollout, holdout resealing, and independent review remain separate gates.
