## §2 新轴 A：存储后端分解（STORAGE-DECOMP，战役首创）

**为什么是新的**：R12-G 封了位置×机制叉积、R13-G 封了 API 面、R14-G
封了引擎态/规模、R15-G 封了协议噪声/引擎代、R16-G 封了内核动词
**计数**层——但十六轮所有裁决都把每个 I/O 动词的**时间**当作单一不可分
的原子数计价。从未有人问：这 96–105 ms/run 里，多少是**存储设备**的
物理时间（可被更快介质压掉），多少是**内核边界 + 页缓存 + JS 序列化**
的时间（与介质无关）？该问题一次性裁决整个「更快磁盘 / 状态根迁移 /
异步落盘」假设族。

**协议**：归档 R12-G part-B 探针组 + 端到端 C1 start→COMPLETED 循环
（与归档矩阵 C1 格同形夹具、固定时钟、顺序 id），双基底各跑一遍：
overlay（`tmpdir()`，生产盘面）vs tmpfs（`/dev/shm`，RAM，零设备延迟
物理极限）。3 批次（seed 0xa17074/75/76），其中第 2 批**基底次序反转**
（tmpfs 先跑）以对照预热偏置。驱动全文、sha256 与关键输出见附录 B。

**行为等价 sim（先决）**：C1 循环在双基底各确定性执行一次，状态树
（runtime/runs/... + runtime/episodes/...）在路径与时间戳规范化后做
sha256 树摘要：**3/3 批次 overlay 摘要 = tmpfs 摘要 =
`51f97767b7dda244…`，逐位一致**。（时间戳规范化沿用归档矩阵协议；
调试确认 episode 存储面以真实时钟落盘，同基底两次运行的原始字节本就

function treeDigest(root: string, normalize: (s: string) => string): string {
  const files: string[] = [];
  const walk = (dir: string): void => {
    for (const name of readdirSync(dir).sort()) {
      const p = join(dir, name);
      if (statSync(p).isDirectory()) walk(p);
      else files.push(p);
    }
  };
  walk(root);
  const h = createHash("sha256");
  for (const f of files) {
    h.update(relative(root, f));
    h.update("\u0000");
    h.update(normalize(readFileSync(f, "utf8")));
    h.update("\u0000");
  }
  return h.digest("hex");
}

function rejectCell(label: string, iters: number, fn: () => void): number {
  let throws = 0;
  let firstMsg = "";
  const wrapped = (): void => {
    try {
      fn();
    } catch (error) {
      throws += 1;
      if (firstMsg === "" && error instanceof DomainValidationError) firstMsg = error.message;
      return;
    }
    throw new Error(`SANITY FAIL: cell "${label}" did not throw`);
  };
  for (let i = 0; i < Math.max(50, iters / 10); i++) wrapped();
  throws = 0;
  const start = performance.now();
  for (let i = 0; i < iters; i++) wrapped();
  const us = ((performance.now() - start) * 1000) / iters;
