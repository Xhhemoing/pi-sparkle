1. **组成假设收口**：历轮每 run 预算（锚点 ×5）隐含五门皆 apply；本轮

2. **guard-2 skip 生产不可达的分布级证人（引理 D 补强）**：F1 在
   429 个 verification ∈ {PASSED, FAILED} 的 fuzz 样本上独立重算
   `shouldApplyThreeLine` 恒真（S11-A-1 引理 D：入口收窄后
   evidence-consistency 维度必观测 ⇒ coverage > 0 且 hasHardPassOrFail
   恒真），三次运行计数逐位一致——五个 skip 类清单即完备清单。
3. **runId-undefined 守卫（child-tracking.ts:28-31）生产死分支**：
   `events[0]?.runId` 仅在空事件表上 undefined，而空表已被
   episodeIdFromEvents undefined 先行拦截；校验过的事件信封每条都带
   runId。该守卫是零成本防御纵深（S9-D-3 同型），保留，不铸 ID。
4. **skip 特化候选无收益池**：guard 次序重排（§0-1）、skipped 常量

function mulberry32(seed: number): () => number {
  let a = seed >>> 0;

  };
