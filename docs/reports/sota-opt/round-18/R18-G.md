## §2 新轴：负载字节形状 × 字符宽度分解（BYTESHAPE，战役首创）

**为什么是新的**：R12-G 封了位置×机制叉积、R13-G 封了 API 面、R14-G
封了规模退化/JIT/GC、R15-G 封了 A/A 噪声地板与引擎代、R16-G 封了内核
动词**计数**、R17-G 封了动词时间的**设备价份额**与拒绝路径——但所有
这些都在**同一负载形状**（R8-G 夹具 AGENT_EVENT，序列化行 315 B 纯
ASCII；N=48 检查点 30 KiB）上计价。「每动词价格 = 固定价 + 每字节
斜率」这一分解从未做过；「字符宽度是否引入非字节比例成本」（UTF-8
多字节、代理对）从未测过。而 `payload.summary` 在域上是**无界**非空
字符串（真实运行中承载代理消息摘要），负载形状是真实自由度。该轴
一次性回答：负载压缩、负载裁剪、重编码、多字节内容——任何「改字节
不改信息」的假设——能否触及数十 ms 落地线。

**方法**（驱动全文见附录 B；3 批次 seed 0xa18081/82/83，固定时钟 +
顺序 id，确定性构造）：

- **A. append 字节梯 + 宽度扫**：ASCII summary 64 B / 512 B / 4 KiB /
  32 KiB 四级（序列化行 314 B–33 018 B），最小二乘拟合固定价 +
  µs/KiB；再以字节对齐（≈4 KiB）CJK（`验`，3 B/字符，1365 UTF-16
  单元）与 emoji（`🚀`，4 B/字符代理对，2048 单元）对拍。
- **B. readAll 字节梯 + 往返摘要**：每形状 300 事件日志（95 KiB–
  1277 KiB），ASCII 梯拟合；每形状 append→readAll 往返对 summary
  数组做 sha256 对比（字节精确性证明）。
- **C. 检查点尺寸梯（同代码路径）**：真实 N=48 检查点（30 KiB）+
  10×/100× 尺寸垫档（`__pad` 字段，CheckpointStore.write 收
  `unknown`，路径不变），拟合持久写固定价 + µs/KiB。
- **D. 计算面每字节归因**：JSON.stringify / validateEvent /
  JSON.parse 按形状扫，切分斜率中的算价 vs 内核价。
- **E. 运行级算术**：R6-G/R10-G 调用画像（300 append / 96 readAll@
  平均半程日志 / 66 cp.write）× 拟合分量。

**三重封死**：

1. 上界不可达：负载字节 = 运行历史本身。事件负载是重放（S1-G-1
   readAll→validateEvent→replayRun 链）与审计（inspection）的输入；
   检查点字节的主体是 N=48 流程图状态（resume 恢复契约）。清零 =
   删除信息 = 正确性变更。
2. 压缩/重编码是契约变更而非优化：持久字节格式是数据面契约（硬
   不变量「CAS / 数据面契约不动」）；恢复尾行协议（readJsonlObjects
   截断尾行恢复）直接工作在原始 JSONL 字节上；且压缩把每字节写价
   （3.1–5.4 µs/KiB）换成每字节算价 + 破坏可审计性（pretty
   checkpoint / JSONL 明文是刻意的检查性属性）。
3. 现实可裁剪余量逐项低于落地线：检查点空白压缩（唯一「信息无损」

/* Least-squares linear fit: cost_us = fixed + slope_per_KiB * KiB */
function fit(points: Array<{ kib: number; us: number }>): { fixed: number; perKib: number } {
  const n = points.length;
  const sx = points.reduce((a, p) => a + p.kib, 0);
  const sy = points.reduce((a, p) => a + p.us, 0);
  const sxx = points.reduce((a, p) => a + p.kib * p.kib, 0);
  const sxy = points.reduce((a, p) => a + p.kib * p.us, 0);
  const perKib = (n * sxy - sx * sy) / (n * sxx - sx * sx);
  return { fixed: (sy - perKib * sx) / n, perKib };
}
