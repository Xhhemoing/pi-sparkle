## 3. 关键裁决细节

### S12-D-1：边界闸 JSON.parse——健全探针存在，但收益是 once-per-command 微秒

**候选主张。** `createCandidate` 对每个 `{`/`[` 前缀内容执行完整
`JSON.parse` 只为检查三个越界键（`kinds` / `targetResource` /
`extraKind`）。R5-D 逐文件收口把该站点记为「KB 级常数、每
createCandidate 一次」但从未有 ID 提出消除机制。本轮机制：JSON 源
文本中键名的每个 ASCII 字母只能以字面量出现或经 `\uXXXX` 转义（JSON
的其它转义 `\" \\ \/ \b \f \n \r \t` 都解码为非字母），故内容若不含
`"kinds"`、`"targetResource"`、`"extraKind"`、`"\u"` 四个子串之任一，
解析结果**不可能**携带越界键，parse 不可能抛错（无效 JSON 本就被
catch 静默放行），可整体跳过。这不是 S1-D-9 的换名：S1-D-9 是 eval
站点 `parseRoutingPolicyContent` 的**双 parse 去重**（复用同一 parse
产物，落地需公开签名）；本条是 createCandidate 站点的**parse 存在性
消除**（探针换 parse），站点与机制均不同，铸新 ID 成立。

**仿真。** 孪生 A（逐字复刻）对 200 组 × 3 seeds 混合输入（markdown
prompt、真实 9.2KB 配置政策、合法/越界 `kinds` 数组、
`targetResource`+`extraKind`、无效 JSON、`\u` 转义键、prose 中含
"kinds" 字样的政策）与真 `assertSingleResourceBoundary` 逐位同判；
健全探针孪生 B 与 A 逐位等价（throws=57–69、sound-skips=48–63 每
seed，覆盖两侧）。**反例**：`{"\u006binds": ["prompt","rubric"]}`——
真实现抛 "candidate must declare a single resource boundary"，健全
孪生 B 因 `\u` 项命中而同抛，**便宜孪生 C（无 `\u` 项）静默放行**
（8/8 运行）。便宜形态即 S9-D-4「编码角落 fail-open」教训在新站点的
精确再现，永不落地。

**收益门（独立第二杀）。** 9.2KB 配置政策是探针 miss（无四子串），
省下的 parse 实测 **9.1–10.4 µs**（real 17.2–18.5 µs vs 探针
8.1–8.2 µs——探针本身要扫 4×9.2KB 子串）；探针 hit 侧（prose 含
"kinds"）付 0.08–0.10 µs 纯税。`createCandidate` 的生产调用方只有
auto-loop / from-episode，每命令至多一次——**once-per-command 微秒类
是验收标准第 3 条的明文 reject 项**，距数十 ms 落地线 3 个量级。

**判决：淘汰，铸 S12-D-1 入排除表。**

### S12-D-2：回放链遍数融合——屏障占 83–89%，生产规模融合是稳定负优化

**候选主张。** `evalRoutingPolicy` 的 O(E) 结构是四遍 pass：
`episodes.map(parseEpisode)`（loadRoutingEvalDataset 内）→
`episodes.map(tasks)`（replayAssignments 内）→ assignTasks×2（批处理
屏障，切片外被调方）→ `episodes.map(actions)` → pairedRecords 单遍。
融合为「屏障前一遍（parse+task 同建）+ 屏障后一遍（action+record
同建）」可省两次数组物化与两轮循环开销。这不是既有 ID 的换名：
S2-D-3 是遍内**双 parseTaskId 去重**（本孪生保留该双调用逐字不动）、
S5-D-2 是 pairedRecords **单遍内迭代形态**、S9-D-1/S8-D-5/S7-D-5 是
**遍内每元素工作**、S9-D-2 是 assertReplayIsolated 的 roots 构造融合
（另一函数）；四遍 pass 的**遍间融合**本身从未获 ID。S11-D-2 是装载
链 parse→restore 融合（不同链），其「相位分解 + 不可融合屏障」裁决
方法论在此复用。

**仿真。** prealloc 形态（`new Array(n)` + 下标写）与 push 形态
（packed 数组）双孪生均与现行链在 actions / records / 完整
gatedComparisonReport / rerunHash（stableStringify+hash32 全路径）上
**逐位等价**（3 seeds × {E=200, E=2000}，8/8 运行）。

**收益门（决定性双杀）。** E=200（生产锚规模）：

```text
delta(prealloc) = −13.9 ~ −199.0 µs / eval（八次测量全负）
delta(push)     = −4.5  ~ −20.4  µs / eval（三次测量全负）
assignTasks×2 屏障 = 0.58–0.67 ms = 链的 83.2–89.4%
```

融合可及面 = 链 − 屏障 ≈ 0.10–0.15 ms，而融合实测把它做**慢**了：
V8 对 `Array.prototype.map` 产出 PACKED_ELEMENTS 数组有形状红利，
prealloc 形态的 HOLEY 数组拖慢下游 assignTasks 迭代，push 形态虽除
该伪影仍稳定为负（融合大循环破坏两个小循环各自的单态 IC）。E=2000
（10× 生产规模）：prealloc **符号翻转**（+304.4 / +453.6 / +577.4 /
+742.4 / +774.7 / +973.3 / +979.0 与 **−514.0** µs 并存），push 同号
为正但仅 +973~+1416 µs——即便取最乐观形态与超生产规模，1.0–1.4 ms
仍低于落地线一个量级。生产规模稳定负 + 放大规模符号不稳/不达线，
验收第 3 条两个子句各自独立否决。

**判决：淘汰，铸 S12-D-2 入排除表。** 新知识：在批处理屏障支配
（>80%）的链上，遍数融合的可及面是屏障余量的真子集，且 V8 的
map-packed 红利使「少一遍」本身变负——这与 S1-A-4（融合实测更慢）、
S3-B-5（V8 内建快路径反例）同族，但首次在本切片的 O(E) 主链上以
双形态 + 双规模完成闭合。

function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

        changeNote: mkNote(`prompt:${tag}${i}`, v1.versionId),
        explicitApproval: true
      });
    }
    versions.push(entry);
  }
  const first = versions[0] as { identity: ResourceIdentity; v1: ResourceVersion; v2?: ResourceVersion };
  registry.rollback({
    identity: first.identity,
    expectedCurrentVersionId: (first.v2 as ResourceVersion).versionId,
    targetVersionId: first.v1.versionId,
    reason: "degradation",
    evidence: ["ev:configured-degradation"],
    automatic: false
  });
  const second = versions[1] as { identity: ResourceIdentity; v1: ResourceVersion; v2?: ResourceVersion };
  registry.rollback({
    identity: second.identity,
    expectedCurrentVersionId: (second.v2 as ResourceVersion).versionId,
    targetVersionId: second.v1.versionId,
    reason: "user",
    evidence: ["ev:configured-user"],
    automatic: false
  });
  registry.retire((versions[2] as { v1: ResourceVersion }).v1.versionId);
  registry.retire((versions[3] as { v1: ResourceVersion }).v1.versionId);
  return built;
}

/* ============================================================
 * S12-D-1: assertSingleResourceBoundary JSON.parse elision via a
 * literal-substring pre-probe (createCandidate site, candidate.ts:144).
 *
 * Claim under adjudication: the boundary guard only throws when the parsed
 * top-level record carries "kinds", or "targetResource"+"extraKind", or a
 * string "extraKind". A JSON source can only spell those key names either
 * literally or through \uXXXX escapes (the only JSON escape able to encode
 * ASCII letters). Therefore:
 *   sound probe  = content contains none of "kinds" / "targetResource" /
 *                  "extraKind" / "\u"  =>  the parse cannot throw => skip it.
 *   cheap probe  = same without the "\u" term => FAIL-OPEN on \u-escaped
 *                  keys (e.g. {"\u006binds": ["prompt","rubric"]}).
 * Twin A = verbatim replica; twin B = sound probe; twin C = cheap probe.
 * Fidelity of twin A is checked against the REAL assertSingleResourceBoundary.
 * ============================================================ */
function boundaryTwinA(identity: ResourceIdentity, content: string): void {
  const trimmed = content.trim();
  if (!trimmed.startsWith("{") && !trimmed.startsWith("[")) return;
  let parsed: unknown;
  try {
    parsed = JSON.parse(content);
  } catch {
    return;
  }
  if (!isRecord(parsed)) return;
  if (Array.isArray(parsed.kinds)) {
    const named = parsed.kinds.filter((kind): kind is string => typeof kind === "string");
    const unique = new Set(named);
    if (unique.size > 1 || (named[0] !== undefined && named[0] !== identity.kind)) {
      throw new DomainValidationError("candidate must declare a single resource boundary");
    }
  }
  if ("targetResource" in parsed && "extraKind" in parsed) {
    throw new DomainValidationError("candidate must declare a single resource boundary");
  }
  if (typeof parsed.extraKind === "string" && parsed.extraKind !== identity.kind) {
    throw new DomainValidationError("candidate must declare a single resource boundary");
  }
}
function boundaryProbeHit(content: string, includeEscapeTerm: boolean): boolean {
  return (
    content.includes("kinds") ||
    content.includes("targetResource") ||
    content.includes("extraKind") ||
    (includeEscapeTerm && content.includes("\\u"))
  );
}
function boundaryTwinB(identity: ResourceIdentity, content: string): void {
  const trimmed = content.trim();
  if (!trimmed.startsWith("{") && !trimmed.startsWith("[")) return;
  if (!boundaryProbeHit(content, true)) return; // sound skip
  boundaryTwinA(identity, content);
}
function boundaryTwinC(identity: ResourceIdentity, content: string): void {
  const trimmed = content.trim();
  if (!trimmed.startsWith("{") && !trimmed.startsWith("[")) return;
  if (!boundaryProbeHit(content, false)) return; // cheap skip (unsound)
  boundaryTwinA(identity, content);
}

/* ============================================================
 * S12-D-2: eval replay-chain O(E) pass fusion.
 * Current chain (private functions inside eval-routing.ts):
 *   raw episodes -> parseEpisode map -> tasks map (replayAssignments)
 *   -> assignTasks x2 (batch barrier, routing slice)
 *   -> actions map -> pairedRecords pass.
 * Fused twins: one pass builds {episode, task} together; after the barrier
 * one pass builds actions and records together. assignTasks itself and the
 * gatedComparisonReport are untouched. Two fusion forms are duelled:
 * preallocated (new Array(n) + index writes; HOLEY elements) and push-built
 * (PACKED elements), ruling out array-shape artifacts.
 * ============================================================ */
interface EpisodeShape {
  readonly episodeHash: string;
  readonly taskId: string;
  readonly role: AgentRole;
  readonly objective: string;
  readonly taskFamily?: string | undefined;
  readonly taskSuccess?: "PASS" | "FAIL" | undefined;
  readonly originalWorkspace: string;
}
interface ReplayActionShape {
  readonly episodeHash: string;
  readonly taskFamily: string;
  readonly taskSuccess: "PASS" | "FAIL" | "UNOBSERVED";
  readonly baselineModel: string;
  readonly candidateModel: string;
  readonly baselineCostUsd: number;
  readonly candidateCostUsd: number;
}
function parseEpisodeReplica(value: unknown, index: number): EpisodeShape {
  if (!isRecord(value)) {
    throw new DomainValidationError(`dataset episodes[${index}] must be an object`);
  }
  if (typeof value.episodeHash !== "string" || value.episodeHash.trim() === "") {
    throw new DomainValidationError(`dataset episodes[${index}] requires episodeHash`);
  }
  if (typeof value.taskId !== "string") {
    throw new DomainValidationError(`dataset episodes[${index}] requires taskId`);
  }
  parseTaskId(value.taskId);
  if (!isAgentRole(value.role)) {
    throw new DomainValidationError(`dataset episodes[${index}] has invalid role`);
  }
  if (typeof value.objective !== "string" || value.objective.trim() === "") {
    throw new DomainValidationError(`dataset episodes[${index}] requires objective`);
  }
  if (typeof value.originalWorkspace !== "string" || value.originalWorkspace.trim() === "") {
    throw new DomainValidationError(`dataset episodes[${index}] requires originalWorkspace`);
  }
  let taskSuccess: "PASS" | "FAIL" | undefined;
  if (value.taskSuccess !== undefined) {
    if (value.taskSuccess !== "PASS" && value.taskSuccess !== "FAIL") {
      throw new DomainValidationError(
        `dataset episodes[${index}] taskSuccess must be PASS or FAIL when present`
      );
    }
    taskSuccess = value.taskSuccess;
  }
  const taskFamily =
    typeof value.taskFamily === "string" && value.taskFamily.trim() !== ""
      ? value.taskFamily
      : undefined;
  return {
    episodeHash: value.episodeHash,
    taskId: value.taskId,
    role: value.role,
    objective: value.objective,
    originalWorkspace: value.originalWorkspace,
    ...(taskFamily !== undefined ? { taskFamily } : {}),
    ...(taskSuccess !== undefined ? { taskSuccess } : {})
  };
}
function catalogCostReplica(catalog: ModelRouterConfig, modelId: string): number {
  const model = catalog.models.find((entry) => entry.id === modelId);
  if (model === undefined) {
    throw new DomainValidationError(`selected model ${modelId} is not in the catalog`);
  }
  return model.estimatedCostUsd;
}
/** Verbatim replica of the current chain: parse map, tasks map, actions map,
 *  pairedRecords pass — four separate O(E) passes around the batch barrier. */
function chainCurrent(
  rawEpisodes: readonly unknown[],
  catalog: ModelRouterConfig,
  baselinePolicy: LearnedRoutingPolicy,
  candidatePolicy: LearnedRoutingPolicy
): { actions: readonly ReplayActionShape[]; records: PairedEvaluationRecord[] } {
  const episodes = rawEpisodes.map((entry, index) => parseEpisodeReplica(entry, index));
  const tasks = episodes.map((episode) => ({
    taskId: parseTaskId(episode.taskId),
    role: episode.role,
    objective: episode.objective
  }));
  const baseline = assignTasks({ catalog, tasks, learned: baselinePolicy });
  const candidate = assignTasks({ catalog, tasks, learned: candidatePolicy });
  const actions = episodes.map((episode, index) => {
    const baselineAssignment = baseline[index];
    const candidateAssignment = candidate[index];
    if (baselineAssignment === undefined || candidateAssignment === undefined) {
      throw new DomainValidationError(`missing assignment for ${episode.episodeHash}`);
    }
    return {
      episodeHash: episode.episodeHash,
      taskFamily: episode.taskFamily ?? baselineAssignment.analysis.family,
      taskSuccess: episode.taskSuccess ?? "UNOBSERVED",
      baselineModel: baselineAssignment.decision.model,
      candidateModel: candidateAssignment.decision.model,
      baselineCostUsd: catalogCostReplica(catalog, baselineAssignment.decision.model),
      candidateCostUsd: catalogCostReplica(catalog, candidateAssignment.decision.model)
    };
  });
  const records: PairedEvaluationRecord[] = [];
  for (const [index, episode] of episodes.entries()) {
    if (episode.taskSuccess !== "PASS" && episode.taskSuccess !== "FAIL") {
      continue;
    }
    const action = actions[index];
    if (action === undefined) {
      throw new DomainValidationError(`missing replay action for ${episode.episodeHash}`);
    }
    const utility = episode.taskSuccess === "PASS" ? 1 : 0;
    records.push({
      episodeHash: episode.episodeHash,
      taskFamily: episode.taskFamily ?? action.taskFamily,
      baselineUtility: utility,
      candidateUtility: utility,
      baselineCostUsd: action.baselineCostUsd,
      candidateCostUsd: action.candidateCostUsd
    });
  }
  return { actions, records };
}
/** Fused twin (preallocated form): pass 1 builds episodes+tasks together;
 *  pass 2 builds actions and records together. The assignTasks barrier and
 *  all per-element work (including the S2-D-3-closed second parseTaskId)
 *  are kept verbatim. */
function chainFused(
  rawEpisodes: readonly unknown[],
  catalog: ModelRouterConfig,
  baselinePolicy: LearnedRoutingPolicy,
  candidatePolicy: LearnedRoutingPolicy
): { actions: readonly ReplayActionShape[]; records: PairedEvaluationRecord[] } {
  const episodes: EpisodeShape[] = new Array(rawEpisodes.length);
  const tasks: { taskId: TaskId; role: AgentRole; objective: string }[] = new Array(rawEpisodes.length);
  for (let index = 0; index < rawEpisodes.length; index += 1) {
    const episode = parseEpisodeReplica(rawEpisodes[index], index);
    episodes[index] = episode;
    tasks[index] = {
      taskId: parseTaskId(episode.taskId),
      role: episode.role,
      objective: episode.objective
    };
  }
  const baseline = assignTasks({ catalog, tasks, learned: baselinePolicy });
  const candidate = assignTasks({ catalog, tasks, learned: candidatePolicy });
  const actions: ReplayActionShape[] = new Array(episodes.length);
  const records: PairedEvaluationRecord[] = [];
  for (let index = 0; index < episodes.length; index += 1) {
    const episode = episodes[index] as EpisodeShape;
    const baselineAssignment = baseline[index];
    const candidateAssignment = candidate[index];
    if (baselineAssignment === undefined || candidateAssignment === undefined) {
      throw new DomainValidationError(`missing assignment for ${episode.episodeHash}`);
    }
    const action: ReplayActionShape = {
      episodeHash: episode.episodeHash,
      taskFamily: episode.taskFamily ?? baselineAssignment.analysis.family,
      taskSuccess: episode.taskSuccess ?? "UNOBSERVED",
      baselineModel: baselineAssignment.decision.model,
      candidateModel: candidateAssignment.decision.model,
      baselineCostUsd: catalogCostReplica(catalog, baselineAssignment.decision.model),
      candidateCostUsd: catalogCostReplica(catalog, candidateAssignment.decision.model)
    };
    actions[index] = action;
    if (episode.taskSuccess === "PASS" || episode.taskSuccess === "FAIL") {
      const utility = episode.taskSuccess === "PASS" ? 1 : 0;
      records.push({
        episodeHash: episode.episodeHash,
        taskFamily: episode.taskFamily ?? action.taskFamily,
        baselineUtility: utility,
        candidateUtility: utility,
        baselineCostUsd: action.baselineCostUsd,
        candidateCostUsd: action.candidateCostUsd
      });
    }
  }
  return { actions, records };
}
/** Push-based fused twin: same two-pass fusion but with packed (push-built)
 *  arrays, ruling out the holey-array shape penalty as the cause of any
 *  negative delta. */
function chainFusedPush(
  rawEpisodes: readonly unknown[],
  catalog: ModelRouterConfig,
  baselinePolicy: LearnedRoutingPolicy,
  candidatePolicy: LearnedRoutingPolicy
): { actions: readonly ReplayActionShape[]; records: PairedEvaluationRecord[] } {
  const episodes: EpisodeShape[] = [];
  const tasks: { taskId: TaskId; role: AgentRole; objective: string }[] = [];
  for (let index = 0; index < rawEpisodes.length; index += 1) {
    const episode = parseEpisodeReplica(rawEpisodes[index], index);
    episodes.push(episode);
    tasks.push({
      taskId: parseTaskId(episode.taskId),
      role: episode.role,
      objective: episode.objective
    });
  }
  const baseline = assignTasks({ catalog, tasks, learned: baselinePolicy });
  const candidate = assignTasks({ catalog, tasks, learned: candidatePolicy });
  const actions: ReplayActionShape[] = [];
  const records: PairedEvaluationRecord[] = [];
  for (let index = 0; index < episodes.length; index += 1) {
    const episode = episodes[index] as EpisodeShape;
    const baselineAssignment = baseline[index];
    const candidateAssignment = candidate[index];
    if (baselineAssignment === undefined || candidateAssignment === undefined) {
      throw new DomainValidationError(`missing assignment for ${episode.episodeHash}`);
    }
    const action: ReplayActionShape = {
      episodeHash: episode.episodeHash,
      taskFamily: episode.taskFamily ?? baselineAssignment.analysis.family,
      taskSuccess: episode.taskSuccess ?? "UNOBSERVED",
      baselineModel: baselineAssignment.decision.model,
      candidateModel: candidateAssignment.decision.model,
      baselineCostUsd: catalogCostReplica(catalog, baselineAssignment.decision.model),
      candidateCostUsd: catalogCostReplica(catalog, candidateAssignment.decision.model)
    };
    actions.push(action);
    if (episode.taskSuccess === "PASS" || episode.taskSuccess === "FAIL") {
      const utility = episode.taskSuccess === "PASS" ? 1 : 0;
      records.push({
        episodeHash: episode.episodeHash,
        taskFamily: episode.taskFamily ?? action.taskFamily,
        baselineUtility: utility,
        candidateUtility: utility,
        baselineCostUsd: action.baselineCostUsd,
        candidateCostUsd: action.candidateCostUsd
      });
    }
  }
  return { actions, records };
}

  }));
