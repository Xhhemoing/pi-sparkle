### 2.2 新轴 A：SYSCENSUS-J（内核边界 syscall 普查，strace 差分法）

方法：`tmp-r16j-sys.ts <cell> <iters>` 每胞单进程驱动一条生产 I/O
路径（夹具/预热与锚点各格同构）；`strace -f -c -w`（限文件/句柄/同步
类 syscall 集）分别跑 ITERS=0 与 ITERS=K，两表差分 ÷K = 逐 syscall
每操作组成与 traced 墙钟（模块加载/夹具/预热在两臂逐字相同，差分
精确抵消）。K：save=200 / jsonl-false=500 / jsonl-true=300 /
cascade=100。两次独立运行（附录 B 全文与两轮输出）。

```text
             每操作 syscall 组成（两轮计数逐整数一致）           traced 墙钟 us/op（run1 | run2）
save         mkdir 1 + statx 1 + openat 1 + write 1 + close 1 = 5   99.0 | 119.0
jsonl-false  mkdir 1 + statx 1 + openat 1 + close 1
             + write 6 (1 数据 + 5 eventfd) + read 5 (eventfd) = 15  134.3 | 133.0
jsonl-true   上行 + openat/close 各 +1（S8-J-2 第二句柄）
             + fsync 1 + eventfd 对 +3 = 24                          639.9 | 657.0
             （fsync 单 syscall 427.8 | 449.8 us = traced 的 65–68%）
cascade      mkdir 2 + statx 4 + openat 4 + close 4
             + write 20 (2 数据 + 18 eventfd) + read 20 (数据+eventfd) = 54   603.8 | 575.0
```

（方法注记：strace -w 每 syscall 注入 ~5–8µs 观察开销，traced 墙钟
约为 untraced 的 2×——absolute 以锚点 untraced 地板为准，census 供
**组成**与**份额**；计数为精确差分，两轮逐整数一致。）

**逐 syscall 分类与裁决**（三类，均为「无候选」）：

1. **契约地板**：save 的 openat+write+close（全量快照数据写 =
   R12-J §2.4 持久化形态评审域）；jsonl 的数据 write（追加语义
   本体）；jsonl-true 的 fsync（**明令禁去**；单 syscall 占 traced
   墙钟 65–68%，untraced 对应 ~220–280µs = fsync=true 与 =false 锚点
   带差，第十六次确认 fsync 是该路径的物理主体）；级联的 2 组数据
   read（S5-J-3 fail-closed 两读）+ 2 数据 write（S6-J-1 串行两写）。
   契约相无合法变形。
2. **自愈探针**：每写/追加 1 组、级联 2 组 mkdir(EEXIST)+statx
   （Node recursive mkdir 对已存在目录 = mkdir 得 EEXIST 后 statx
   验目录性）。untraced 直测 **1.36–1.52µs/组**（见证 W2，附录 C）
   ——S7-J-6 原判据（1.08µs，自愈语义收窄拒）在内核层再确认；
   S5-G-1/S6-E-3 同族。每 run 合计 <10µs。
3. **libuv 异步机器**：jsonl/级联的 eventfd write+read 对（线程池
   完成唤醒）+ 线程池调度——save 胞（纯同步路径）**恰好为零**是
   机制识别的对照见证。untraced 直测：同一 `mkdir(existing,
   recursive)` 同步 1.36–1.52µs vs 异步 21.4–21.6µs ⇒ **每异步 fs
   操作孤立机器成本 ~20.1µs（上界；持续负载下线程不眠更低）**。
   由此得本切片最锐利的物理刻画：**生产尺寸下 jsonl-false 追加地板
   （60.6–68.2µs）的主体是 4–5 次异步操作的调度+syscall 固定成本，
   而非字节传输**（§2.3 Cell L 字节斜率 1.65–1.85µs/KB ⇒ 140B 生产
   行字节项 ~0.3µs）。消除路径全部撞死：同步化改公开异步签名
   （X0-4）；持久句柄跨调用缓存（X1-1 + S8-J-2 句柄面）；攒批
   （S5-G-5 逐消息持久性 + S6-J-4 read-your-writes）；换 io_uring/
   平台面（S9-C-2 构建面同族）。

**预算收口**：三类合计即锚点地板本身；其中非契约可想象项（自愈探针
+ 机器成本）每操作 ~5–100µs、切片每命令 I/O 操作数个位（R7-J 配置态
普查继承：追加 1–5 次/run、preference 写 0–5 次/命令、级联仅删除
命令 ×1）⇒ **每 run 非契约内核预算 <0.5ms**，距落地线（数十 ms）
1.5–3 个数量级，且逐项已闭。**该轴不产生任何候选。**

1. **越线点全部距生产形态 2–4 个数量级**：生产 preference 值为习惯

   10²–10³B（距行字节越线 ~4 个数量级）。
2. **body 字节轴被 schema/策略层结构性封闭**（R16-A id 字节轴封闭

   落盘、不可能抬升级联成本；满店顶格 400 字符 body 的级联仍 ~1ms

3. **越线规模上无切片可寻址相位**：三条路径在越线规模上的增量成本
   全部是 payload 字节本身的 stringify/write/read/parse——字节面
   变更 = S4-G-6/S6-E-4 磁盘数据面家族；全量快照形态 = R12-J §2.4
   数据面契约评审域；级联 read+rewrite = S5-J-3/S6-J-1 契约相

4. summary 无上限是**策略面事实**而非代码低效：若未来治理要求对

   性能优化，不铸 ID。**该轴不产生任何候选。**

import re, sys
def parse(path):
    rows = {}
    for line in open(path):
        m = re.match(r"\s*([\d.]+)\s+([\d.]+)\s+(\d+)\s+(\d+)\s+(\d+)?\s*(\w+)\s*$", line)
        if m:
            pct, seconds, usecs, calls, errors, name = m.groups()
            rows[name] = (int(calls), float(seconds))
    return rows

names = sorted((set(base) | set(k)) - {"total"})
total_c = total_t = 0.0
for n in names:
    bc, bt = base.get(n, (0, 0.0))
    kc, kt = k.get(n, (0, 0.0))
    dc, dt = (kc - bc) / K, (kt - bt) * 1e6 / K
    if abs(dc) < 0.005 and abs(dt) < 0.05:
        continue
    total_c += dc
    if abs(dc) >= 0.5:
        total_t += dt
        print(f"  {n:12s} {dc:8.2f} calls/op   {dt:9.2f} us/op")
    else:
        print(f"  {n:12s} {dc:8.2f} calls/op   [count~0: startup-time jitter, time excluded]")
