R1-E..R20-E 的十三个维度没有任何一维变动过「标识符字符串本身长什么
样、有多少个不同的」。E 切片是全库最重的 id 消费面之一：五个
taskId 键 Map（`signals.ts:131-135`，MODEL_ROUTED set / TASK_RESULT
与 JUDGE_DECISION get）、routes Map（`from-episode.ts:195+`）、
`${modelId}|${taskFamily}` 去重键（`from-episode.ts:77`）、
`${projectId}::${modelId}` 分组键（`diagnostics.ts:26`）、
`applyLearnedRouting` 的 avoided Set 构建 + `allowedModels.includes`
字符串等值扫描（`learned-routing.ts:198-213`）、bandit 臂 Record 与
`arms.includes` 线性扫描（S2-E-3 参照体）、fbk\_ 铸造哈希拼接
（`auto-loop.ts:207`）。而二十轮夹具 id 几何（12ch/2–7ch）与生产
几何（`domain/ids.ts` 40ch、域内封顶 68ch；`config/model-ref.ts`
provider/model 引用 22–29ch）从未对齐过。本轮双剂量定价（8 次套件
运行 = 5 × v22.22.2 + 3 × v22.14.0，108/108 sanity ×8 全绿；数字见
结论 1–2，此处不重抄），关键机制事实与裁决：

- **L 剂量平坦性的机制**：V8 对字符串做一次性散列并缓存于对象头，
  Map 探测先比散列再比内容；夹具内每个 id 都是复用引用（同一
  数组池取值），等值比较绝大多数走指针相等快路径——键长从 12ch 到
  68ch 不进入任何热路径的每次比较成本。域内三档总量 15.6–17.3 µs
  同带、无单调斜率，即**前二十轮全部 CPU 锚点在生产 id 几何下原样
  成立**，保真度缺口定价为零。
- **fbk\_ 铸造斜率的属地**：唯一实测长度斜率位点（1.1–1.5 →
  2.6 µs/signal @ 生产几何）由 `hash32` 吃拼接串驱动，支配项是
  400ch 封顶的 summary 而非 id；该表达式仅对带 episodeId 的信号
  执行、每信号一次、后随 `appendFeedback` 磁盘追加（I/O 支配，
  R2-E/R4-E 谱系）。预散列/截断改 id 语义 = 数据面契约变更，拒列。
- **K 剂量线性位点的属地与算术**：bandit 臂线性扫描
  （`arms.includes` + 逐臂 Record 初始化）0.15–0.2 µs/臂——生产
  臂数 = 目录内被路由过的模型数（个位数），幻想 30 臂 4 µs/run；
  实现体在 `src/routing/bandit.ts`（B 辖区），E 内只持调用边。
  `applyLearnedRouting` 的 (M, |avoid|) 超线性格 1.5 µs/task
  @ (30,30) 距 S13-B-1 重开线 18×、距落地线 660×——S13-B-1 的
  「生产写入方不可达」裁决在基数维度上获得第二个实测支撑点
  （|avoid| 由 `${modelId}|${taskFamily}` 去重键封顶为
  相异失败组合数，本轮 K 剂量 T×M 网格实测 outcomes≤5）。
- **T / P×M 平坦性**：相异 taskId 数与 (项目 × 模型) 分组网格在
  固定 E/S 下不产生任何可测基数税（Map 装载因子远低于重散列阈值，
  分组数只是把同样多的信号摊进更多短列表）。

**裁决**：该轴在频率（id 几何不改变调用频次）× 单价（域内全部格
同带或距门槛数百倍）× 属地（斜率位点 I/O 支配 + 数据面契约；线性
位点 B 辖区 + S13-B-1 邻域）三端封死，**不产生候选**。「标识符
几何」维度就此与前十三维正交封口：成本 = f(构成) 与键几何解耦，
域内证明 + 越域斜率探针双重钉死。
