## §2 新轴：调度窗口 × 图宽度计数剖面定价（SCHEDWIN，战役首创）

**为什么是新的**：R16-G…R19-G 把每个 I/O 契约动词的**单价**写成
f(调用数, 设备, 负载字节, 路径名) 并扫毕全部四输入；R20-G 补扫进程
环境维度（XPROC）。但每 run 地板从来是 **单价 × 计数剖面** 的乘积，
而计数剖面（300 append / 96 readAll / 66 cp.write）在全部二十轮里是
一个**冻结常数**（R6-G 普查值）。该剖面在机制上不是常数：
`runFlowchartLoop` 每推进轮付固定节拍（2 cp.write + 2 readAll +
1 LEDGER_UPDATED 追加 + 2 pause 轮询），轮数 =
**rounds(图宽度, maxConcurrentNodes)**——图宽度由用户的 children 依赖
结构决定（`compileChildrenToFlowchart` 独立根数），调度窗口
`maxConcurrentNodes` 是公开输入（默认 4）。二十轮的测量从未让窗口
束紧过：矩阵图宽度 ≤2、fleet 链宽度 1、`checkpointFor` 的 W=2 只是
静态负载。「计数剖面 = f(width, W) 的形状与价格」是每 run 地板因式
分解中**最后一个未扫因子**。该轴一次性回答：(a) 剖面对配置的响应是否
存在超线性病理；(b) 窗口是否语义自由（若否，存在并发 bug 伪装的优化
空间）；(c) 「调大默认窗口 / 削减轮内节拍」假设族能否触及数十 ms
落地线。

**方法**（驱动全文见附录 B；正式三批 seed 0xa21081/82/83 + 冒烟批
0xa21080 复核复现性，四批逐字节同码。固定时钟 + 每格重启的顺序 id，
确定性构造；seed 仅标注批次）：

- **图形三态（全部经生产编译路径 `compileChildrenToFlowchart`）**：
  `chain8`（8 节点全链，宽度 1 = 窗口永不束紧的对照组）；`wide16`
  （16 独立根，纯宽度 16）；`mixed48`（归档基准同款 48-children 夹具，
  33 根 + 15 链依赖，宽度 33——即二十轮 N=48 检查点负载所来自的图）。
- **窗口梯**：W ∈ {1, 2, 4, 8, 16}（4 = 生产默认；`limits` 统一另传
  maxRounds=96 使唯一变元是 W）。
- **每格协议**：真实 `startFlowchartRun` start→COMPLETED × 5 重复，
  新鲜 mkdtemp 状态根，原型插桩计数（append / readAll / 累计读事件数 /
  cp.write / pause 轮询 / episode 三动词 / LEDGER 追加），逐重复墙钟。
- **等价见证**：(1) 每格 5 重复计数剖面必须逐位相同；(2) 同图形跨全部

      const out = await startFlowchartRun(deps, {
        projectRoot, flowchart, objective: `${shape.name} at window ${w}`,
        limits: { maxConcurrentNodes: w, maxConsecutiveStalls: 3, maxRounds: 96 },
        childResults
      });
      wallMs.push(performance.now() - t);
      if (out.status !== "COMPLETED") throw new Error(`unexpected status ${out.status} for ${shape.name} w=${w}`);
      runIds.push(out.runId);
      ops = counts;
      rounds = out.snapshot.ledger.round;
      nodeDigest = nodeMapDigest(out.status, out.snapshot);
      profiles.push(JSON.stringify(counts));
    }
    const profileStable = profiles.every((p) => p === profiles[0]);
    const normalize = (raw: string): string =>
      raw.replaceAll(stateRoot, "<STATE>").replaceAll(projectRoot, "<PROJ>")
        .replace(/\d{4}-\d{2}-\d{2}T[0-9:.]+(Z|[+-]\d{2}:\d{2})/g, "<T>");
    const hash = createHash("sha256");
    for (const rid of runIds) {
      const dir = join(stateRoot, "runtime", "runs", rid);
      hash.update(normalize(await readFile(join(dir, "events.jsonl"), "utf8")));
      hash.update(normalize(await readFile(join(dir, "checkpoint.json"), "utf8")));
    }
    wallMs.sort((a, b) => a - b);
    return {
      shape: shape.name, w, rounds, ops,
      meanMs: wallMs.reduce((a, b) => a + b, 0) / wallMs.length,
      minMs: wallMs[0]!,
      nodeDigest, artifactDigest: hash.digest("hex"), profileStable
    };
  } finally {
    rmSync(stateRoot, { recursive: true, force: true });
  }
}
