### 2.2 本轮换名检查（5 项，逐项拒收，不铸 ID）

1. **`providers-config.ts` 重复 `parseModelRef`**（L100–104
   `setDefaultModels` 对 `input.primary`/`input.fast` 各解析两次取

   进程原子性契约本体（锁内取最新态）；记忆化 = 凭据围栏上的
   fail-open 陈旧态，触双重不变量；`read`/`list` 为 once-per-auth-
   command 数十 µs 小文件读。承重格零通量（bench 态无 auth.json；
   凭据解析惰性于请求时）。**REJECT + 凭据围栏，关。**
3. **`pi-executor.ts` collect-then-replay 事件缓冲**（L158
   `collected` 收满 → L196 重放 yield）。裁决：改为流式直出会改变

   由外部模型调用支配（latencyMs 本体）。**REJECT（契约承载 +
   真实规模零收益）。**
4. **`cluster-tools.ts` 每 execute 重建三个 AgentTool 对象**
   （pi-executor L159 每请求 `createClusterTools(request.cluster)`）。
   裁决：工具闭包按设计绑定**每请求** `ClusterSessionView`（spawn/
   send/inbox 记账目标），提升为常量即改变会话绑定语义；构建成本
   ns–µs 级/次，路径由模型调用支配。**REJECT（物理绑定 + 亚
   噪声）。**
5. **`listed-model-lazy.ts` 每命中 `Object.keys(ns).filter(
   endsWith("_MODELS"))` 表扫描**（L26）。裁决：首次 import 后走
