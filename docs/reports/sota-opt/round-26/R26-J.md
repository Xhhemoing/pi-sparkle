## 2. 第二十六遍枚举：偏好持久面删除坐标（DELINV，四胞 + 逐胞账户见证）→ 全部「无候选」→ 诚实空结果

### 2.1 轴定义与战役首创性（非重铸论证）

**受控变量**：偏好持久面的**删除坐标**三分量——(a) 会话变异动词
组成（record vs delete 的字母表混合比 δ）；(b) delete 目标在活
数组中的位置 p；(c) 持久**墓碑存量** T 及其在写/水合/export 三腿
上的携带。

**二十五轮从未拉伸的证据**（逐报告核对）：

- R12-J..R25-J 全部计时 store 会话只发 record\*（锚点谱系、CALLB
  P2 三排程、VALCLASS P1 七剂量、COTARG P1 四胞——无一含 delete
  动词），恒居「δ=0、T=0」append-only 角。
- R2-J（及 R11-J 复引）对 `deleteObservation` 只有**站点级定性**
  裁决「findIndex+splice 被 save 支配」——从未把删除份额、目标
  位置或墓碑存量当剂量。
- R18-J 跳径普查只定价 delete-**miss**（`index < 0` 直返 false，
  63–73ns 零 I/O）——hit 族从未计时。
- R20-J C2 的墓碑剂量在 loop-eval 侧：把 `tombstones` 当纯函数的
  现成 ReadonlySet **输入**（每观察一次 `Set.has`，站点零生产调用
  方）；store 侧**铸造**墓碑的动词、`saveToDisk` 对
  `Array.from(tombstones)` 的**每写序列化**、`loadFromDisk` 的
  Set 填充、export 的 `listTombstones` 腿在任何一轮都不是受控
  变量。⇒ **战役首创**。

**与六个已闭轴的区分**（论证负担逐条卸）：

- **非 R20-J 组成重铸**：R20-J 的变量是固定动词字母表内的**记录
  类混合**；本轴的变量是**动词字母表本身**加上它铸出的持久存量。
  平面不同（纯函数输入 vs 有副作用持久面）、机制不同（每观察
  Set 查询 vs 每写序列化/每命令水合/export 列举）。
- **非 CALLB 重铸**：CALLB 明文钉死「固定记录多重集」，动的是
  边界粒度与消费放置；其轨迹积分框架恰好证明动词混合是它未剂量
  的 state_t 移动方式。本轴每变异恰一次 API 调用（排程钉死）。
- **非 R19-J 次序/重数重铸**：插入次序与 createdAt 序列逐胞相同；
  删除目标位置是对**活记录的寻址坐标**，非插入序也非重投递。
- **非 R14-J 规模重铸**：T 在活库存 N 恒 500 下独立变化——历轮
  规模轴只长 observations，从未有第二库存坐标。
- **非 VALCLASS / SHAPEK / COTARG 重铸**：值类恒 string 2 字符、
  单字面量构造器、键拓扑钉死（P1 = R25-J D 角构造器逐位同源，
  DEL0 胞 DISK 终态 145909 B 与 COTARG P1 文件字节直等——谱系
  交叉验证）；record-count 差是 M 恒定下动词组成的定义性后果
  （VALCLASS 字段表示辩护的同构）。
- **非姊妹轴移植**：非 R26-F 输入存储态面（V8 integrity/elements
  引擎态——墓碑是**领域状态**坐标）；非 R24-I 适应态坐标
  （adaptation registry，他区他店）；非 R26-B 约束腿 / R26-G 边
  条件种 / R26-D 注入缝 / R26-A locale / R25-\* 各轴——逐条对照
  见 §0。

**分支族选择**（读码定位）：`store.ts deleteObservation` L242–250

### 2.7 裁决

四胞全部「无候选」，三重收口：

1. **动词税不存在**：P1 组成响应完全由库存轨迹解释（方向 =
   删除更便宜），P3 动词本体（扫描+移位）在地板上符号不稳；
   delete-hit 的每次全量 rebuild+save 与 record 同价即 R2-J 定性
   裁决的剂量化证实。
2. **携带/水合/export 响应真实但全是线性字节契约**，任何优化
   形态撞已闭族：序列化片段缓存 = X1-1 模块级隐藏缓存；墓碑拆分
   独立文件或改追加日志 = 磁盘数据面字节发散（S4-G-6 族）+ 打破
   observations/tombstones 快照原子配对——单故障留下「观察已删
   而墓碑未落」或反向的复活窗口，正是 S6-J-1 在 feedback 面关死
   的同型 fail-open；压缩/丢弃墓碑 = privacy 契约本体
   （record-classes L119「dataset export always lists tombstone
   ids」、deletion.ts P0 Q2 签核、clearPreferences 保留语义）；
   export 去 pretty-print = S4-G-6/S6-E-4 族审计工件字节发散。
3. **生产剂量微小**：T = 该 state root 历史 `pref delete` 手工
   隐私操作数（现实个位～十位）。T=10 时携带 +0.35–0.38µs/写
   （400–800µs 地板深度亚噪声）、水合 +1.2–1.4µs/命令、export
   亚 µs；越两位数 ms 落地线需 T≈3×10⁵ 并叠持续写通量——比
   SHAPEK 的双重幻想再多一重（墓碑只能由逐条手工命令铸造）。

按纪律不铸任何 S26-J-\* ID；DELINV 只入本报告（父代理计划禁令，
不写 EXCLUSIONS 行）。完备性洞已补：删除坐标三分量首次受控点火
并被见证——洞内没有优化。

{
  const S = 25;
  const SEED = 500;
  const M = 200;
  const RUNS = 3;
  type Cell = "DEL0" | "DEL10" | "DEL25" | "DEL50";
  const CELLS: readonly Cell[] = ["DEL0", "DEL10", "DEL25", "DEL50"];
  const isDelete = (cell: Cell, m: number): boolean =>
    cell === "DEL10" ? m % 10 === 9 : cell === "DEL25" ? m % 4 === 3 : cell === "DEL50" ? m % 2 === 1 : false;

  // R25-J D-corner record generator (explicit on "ka" from the disjoint
  // pool, inferred on "kb"): single literal constructor, single key order,
  // all-string 2-char keys/values, weights 1/0.5, project scope only.
  function makeObs(i: number): PreferenceObservation {
    const p = Math.floor(i / S);
    const explicit = p % 10 >= 4 && p % 10 <= 6;
    const poolIdx = p % 3 === 2 ? 1 : 0;
    return {
      id: `evd_${pad(i, 8)}`,
      scope: "project",
      scopeKey: `sk${pad(i % S, 2)}`,
      key: explicit ? "ka" : "kb",
      value: explicit ? ["vx", "vy"][poolIdx]! : ["va", "vb"][poolIdx]!,
      evidenceEpisodeId: EPISODE,
      weight: explicit ? 1 : 0.5,
      createdAt: stamp(i),
      explicit,
      recurrenceCount: 1
    };
  }

  type Mutation = { readonly kind: "record"; readonly obs: PreferenceObservation } | { readonly kind: "delete"; readonly id: string };

  interface Script {
    readonly mutations: readonly Mutation[];
    readonly records: number;
    readonly deletes: number;
    readonly deletedIds: readonly string[];
    readonly meanLive: number;
  }

  // Precompute the whole mutation script untimed via a live-id mirror so the
  // timed loop is a pure dispatch (no listObservations() copies inside it).
  function buildScript(cell: Cell): Script {
    const mirror: string[] = [];
    for (let i = 0; i < SEED; i++) mirror.push(`evd_${pad(i, 8)}`);
    const mutations: Mutation[] = [];
    const deletedIds: string[] = [];
    let records = 0;
    let liveSum = 0;
    for (let m = 0; m < M; m++) {
      if (isDelete(cell, m)) {
        const idx = Math.floor(mirror.length / 2);
        const id = mirror[idx]!;
        mirror.splice(idx, 1);
        deletedIds.push(id);
        mutations.push({ kind: "delete", id });
      } else {
        const obs = makeObs(SEED + m);
        mirror.push(obs.id);
        records += 1;
        mutations.push({ kind: "record", obs });
      }
      liveSum += mirror.length;
    }
    return { mutations, records, deletes: deletedIds.length, deletedIds, meanLive: liveSum / M };
  }

/* ================= P3: delete-target position dose ======================= */
{
  const N = 700;
  const DELS = 200;
  const RUNS = 3;
  type Pos = "HEAD" | "MID" | "TAIL";
  const CELLS: readonly Pos[] = ["HEAD", "MID", "TAIL"];

  interface Script {
    readonly targets: readonly string[];
  }

  function buildScript(pos: Pos): Script {
    const mirror: string[] = [];
    for (let i = 0; i < N; i++) mirror.push(`evd_${pad(i, 8)}`);
    const targets: string[] = [];
    for (let d = 0; d < DELS; d++) {
      const idx = pos === "HEAD" ? 0 : pos === "MID" ? Math.floor(mirror.length / 2) : mirror.length - 1;
      targets.push(mirror[idx]!);
      mirror.splice(idx, 1);
    }
    return { targets };
  }

  const scripts = new Map<Pos, Script>(CELLS.map((pos) => [pos, buildScript(pos)]));

  interface SessionOut {
    readonly perDeleteUs: number;
    readonly obsJson: string;
    readonly tombs: string;
    readonly fileBytes: number;
  }

  function runSession(pos: Pos, leg: "MEM" | "DISK"): SessionOut {
    const script = scripts.get(pos)!;
    const dir = leg === "DISK" ? mkdtempSync(join(tmpdir(), "r26j-dv-p3-")) : undefined;
    resetPreferenceStore();
    configurePreferencePersistence(undefined);
    if (dir !== undefined) configurePreferencePersistence(join(dir, "preferences.json"));
    for (let i = 0; i < N; i++) recordObservation(makeWideObs(i));
    const t0 = hr();
    for (const id of script.targets) deleteObservation(id);
    const t1 = hr();
    const out: SessionOut = {
      perDeleteUs: us(t0, t1, DELS),
      obsJson: JSON.stringify(listObservations()),
      tombs: JSON.stringify(listTombstones()),
      fileBytes: dir !== undefined ? statSync(join(dir, "preferences.json")).size : 0
    };
    assertEqual(`P3 ${pos}/${leg} live`, listObservations().length, N - DELS);
    assertEqual(`P3 ${pos}/${leg} tombstone sequence`, listTombstones(), script.targets);
    resetPreferenceStore();
    configurePreferencePersistence(undefined);
    if (dir !== undefined) rmSync(dir, { recursive: true, force: true });
    return out;
  }

  for (const pos of CELLS) {
    runSession(pos, "MEM");
    runSession(pos, "DISK");
  }

  const bytesByPos = new Map<Pos, number>();
  for (const leg of ["MEM", "DISK"] as const) {
    for (const pos of CELLS) {
      let best = Infinity;
      let sum = 0;
      let last: SessionOut | undefined;
      for (let r = 0; r < RUNS; r++) {
        const out = runSession(pos, leg);
        best = Math.min(best, out.perDeleteUs);
        sum += out.perDeleteUs;
        last = out;
      }
      const replay = runSession(pos, leg);
      assertEqual(`P3 ${pos}/${leg} determinism obs`, replay.obsJson === last!.obsJson, true);

        `P3 position ${leg.padEnd(4)} ${pos.padEnd(4)} (N=${N}, deletes=${DELS}): min=${fmt(best)} mean=${fmt(sum / RUNS)} us/delete${leg === "DISK" ? `  fileBytes=${last!.fileBytes}` : ""}`
      );
    }
  }
  assertEqual("P3 bytes HEAD=MID", bytesByPos.get("HEAD"), bytesByPos.get("MID"));
  assertEqual("P3 bytes HEAD=TAIL", bytesByPos.get("HEAD"), bytesByPos.get("TAIL"));
  console.log(`P3 fidelity: determinism + inventory + exact cross-cell byte equality (${bytesByPos.get("HEAD")} B) passed`);
}
