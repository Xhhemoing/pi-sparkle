## 结论

**无可落地的新更优解，本轮生产代码零改动，切片维持关闭
（MORE_OPTIMA=no）。** 第二十九遍为本切片**连续第十八次完全空枚举**
（R12-G…R28-G、本轮），并新增一条前二十八轮从未做过的真实新轴：
**M2 监督引擎裁决格 / M2 supervised-engine adjudication lattice face
（战役首创）**——本切片藏着**第二台运行引擎**：`src/run/supervisor.ts`
的 M2 DAG 轮循环（`runSupervisorRounds`），与二十八轮反复定价的
flowchart-run 引擎结构不同的任务裁决机械。它对每个跑完的子任务做一次
三方裁决：`DeterministicJudge`（judge.ts:61-71）把 verification 种类映
射为裁决（PASSED→APPROVED / FAILED→REJECTED / UNOBSERVED→
NEEDS_USER_DECISION），裁决臂（supervisor.ts:410-428）再经
`toTaskOutcome`（:114-126，PARTIAL 折叠为 SUCCESS）与
`applyTaskOutcome`（scheduler.ts:119-140）落成任务态；**尝试预算 vs
停滞预算的竞速**决定 run 终态类；resume 时的**孤儿租约恢复**
（supervisor.ts:253-266）对 RUNNING 租约合成一次 TIMEOUT 转移。被扫格
= **裁决来源**（verification PASSED / FAILED / UNOBSERVED × 有无终端
TASK_RESULT × executor 无终端宣称成功 / 中途抛错 / 逐尝试超时）×
**子结局**（SUCCESS / PARTIAL / FAILURE / CANCELLED / TIMEOUT）×
**预算竞速两体制**（maxAttempts ⋛ maxConsecutiveStalls）+ **孤儿租约
恢复维**。该格不是死代码而是 M2 引擎裁决本体：

- **生产可达仅一扇门且是半扇**：`startSupervisedRun` **无任何 CLI
  调用方**（M2 起跑纯测试面；cli/main.ts 全文无引用），唯一生产入口是
  `resume --supervised`（main.ts:1018-1022 按需动态 import），而它要求
  磁盘上已存在一份 M2 事件日志——比 R28-G 门面「用户手写 flowchart
  JSON 一次性流量」更强的**字面零缺省剂量**（缺省生产流量连一格都
  不踩）。
- **裁决臂三条**（:410-428）：APPROVED → COMPLETED + 进度记账；
  REJECTED → `applyTaskOutcome(toTaskOutcome(子结局))`（FAILURE/TIMEOUT
  → BLOCKED→READY 重试梯或 FAILED；**SUCCESS → COMPLETED；CANCELLED →
  CANCELLED**）；NEEDS_USER_DECISION → BLOCKED + userDecision 进度。
- **验证缺省 UNOBSERVED**（:388）：无终端结果（超时 / 抛错 / executor
  无终端宣称成功 / 终端自带 UNOBSERVED）一律折入 NEEDS_USER_DECISION。
- **孤儿租约恢复**（:253-266）：resume 重建的 RUNNING 租约无活工作者，
  立即 TASK_LEASE_EXPIRED + 合成 TIMEOUT 转移（BLOCKED→READY 重试或
  FAILED），不等墙钟到期。

而二十八轮 + 既有集成测试只驱动过该格的**恰好四格**：
test/integration/m2/ 两件驱动 PASSED×SUCCESS（APPROVED 主线）、
FAILED×FAILURE @3/3（重试梯至 BLOCKED）、FAILED×FAILURE @1/10

裁决格），历轮 §1 锚点把 `DeterministicJudge.decide` 当纯计算核每轮
定价（0.14 µs）但从不变维。**PARTIAL 折叠臂、REJECTED×SUCCESS /
REJECTED×CANCELLED 矛盾格、UNOBSERVED 燃烧拓扑（含无终端/抛错/超时
三来源）、超时不对称、预算竞速边界体制 2/10、孤儿租约恢复——没有

`startSupervisedRun`/`resumeSupervisedRun` + 脚本化 executor + 真实

2. **裁决机械全部 ns/µs–低 ms 级**：裁决计算面 judge.decide

   0.065–0.066 µs、resume 重建 4.0–4.2 µs——全在全局计算顶
   0.290–0.298 ms/run 的既有封顶之内；I/O 侧最重结构格 L3（三轮重试

3. **矛盾格修复与解锁面补齐是行为改变，撞纪律**：REJECTED×SUCCESS /

**语义普查事实（非性能洞，随轴入档，proposal-first 不作 Outcome
声称）**：(a) **REJECTED×SUCCESS 矛盾格**（L5）——verification FAILED
的终端若自带 outcome SUCCESS，裁决 REJECTED 后 `applyTaskOutcome`
仍按 SUCCESS 落 COMPLETED@0：法官的拒绝对结局映射**无否决权**，任务
零重试完成、run COMPLETED；(b) **REJECTED×CANCELLED 矛盾格**（L6）
——任务落 CANCELLED 后 `canProgress=false` 且 `failed=[]`，run 终态
**RUN_COMPLETED**；(c) **UNOBSERVED 收敛燃烧**（L7–L11）——五种无验证
来源（UNOBSERVED×SUCCESS / ×FAILURE、无终端宣称成功、executor 抛错、
逐尝试超时）全部收敛 NEEDS_USER_DECISION → 任务 BLOCKED，而 M2 轮
循环**没有任何用户决策面**（无注入/应答通道触达 M2 BLOCKED 任务），
run 恒以 1 个 userDecision 进度轮 + maxConsecutiveStalls 个停滞轮
收 RUN_BLOCKED——userDecision 记进度反而**多烧整一个停滞周期**
（4 轮 vs 3 轮）；(d) **超时双政策不对称**——活尝试超时走 (c)（监督
层永不重试，协调器内部已按 node.maxAttempts 重试），孤儿租约超时走
`applyTaskOutcome(TIMEOUT)` → BLOCKED→READY**重试**（L12）：同一引擎
两种超时政策；(e) **任务级预算双记**——node.maxAttempts 同时充当
协调器**轮内**尝试预算（:374）与监督层**跨轮**预算上限（:409,:417），
持续超时任务单轮即可烧满 maxAttempts 次 executor 真跑（L11：
TASK_TIMEOUT×2 + TASK_RETRY×1）。均不构成计算洞，不铸 ID。

/* ---- scripted executors (verdict sources) ------------------------------- */

function terminalMessage(
  request: AgentExecutionRequest,
  outcome: ProtocolOutcome,
  verification: VerificationKind
): TaskResult {
  const evd = `evd_${request.taskId}` as never;
  return {
    protocolVersion: 1,
    id: createMessageId(UUID),
    occurredAt: T0,
    runId: request.runId,
    taskId: request.taskId,
    from: request.agentInstanceId,
    to: SUPERVISOR,
    type: "TASK_RESULT",
    outcome,
    summary: `terminal ${outcome}/${verification}`,
    artifactIds: [],
    evidenceIds: [evd],
    verification: { kind: verification, evidenceIds: [evd] },
    ...(outcome === "FAILURE" ? { failure: { category: "TOOL_ERROR", detail: "scripted" } } : {})
  };
}

/** Emits one legal TASK_RESULT with the requested outcome x verification. */
class TerminalExecutor implements AgentExecutor {
  constructor(private readonly outcome: ProtocolOutcome, private readonly verification: VerificationKind) {}
  async *execute(request: AgentExecutionRequest, signal: AbortSignal): AsyncIterable<ExecutionEvent> {
    if (signal.aborted) {
      yield { type: "EXECUTION_FINISHED", outcome: "CANCELLED" };
      return;
    }
    yield { type: "MESSAGE", message: terminalMessage(request, this.outcome, this.verification) };
    yield { type: "EXECUTION_FINISHED", outcome: "SUCCESS" };
  }
}

/** Claims executor success but never sends a terminal TASK_RESULT. */
class NoTerminalExecutor implements AgentExecutor {
  async *execute(_request: AgentExecutionRequest, _signal: AbortSignal): AsyncIterable<ExecutionEvent> {
    yield { type: "EXECUTION_FINISHED", outcome: "SUCCESS" };
  }
}

/** Throws mid-stream (transport/protocol explosion). */
class ThrowingExecutor implements AgentExecutor {
  // eslint-disable-next-line require-yield
  async *execute(_request: AgentExecutionRequest, _signal: AbortSignal): AsyncIterable<ExecutionEvent> {
    throw new Error("executor exploded");
  }
}

/** Hangs until the attempt timer aborts the combined signal. */
class HangingExecutor implements AgentExecutor {
  async *execute(_request: AgentExecutionRequest, signal: AbortSignal): AsyncIterable<ExecutionEvent> {
    await new Promise<void>((resolve) => {
      if (signal.aborted) return resolve();
      signal.addEventListener("abort", () => resolve(), { once: true });
    });
  }
}

interface Cell {
  name: string;
  status: string;
  rounds: number;
  taskStatusPath: string;
  parentTerminal: string;
  ops: OpCounts;
  parentAppends: number;
  childAppends: number;
  judgeVerdicts: string;
  retries: number;
  leaseExpired: number;
  ms: number;
}

const registry = createAgentProfileRegistry(defaultAgentProfiles());

async function runCell(
  name: string,
  executor: AgentExecutor,
  tasks: TaskNode[],
  runLimits: RunLimits,
  stateRoot: string,
  projectRoot: string,
  cells: Cell[],
  idOffset: number
): Promise<{ runId: RunId; events: Event[] }> {
  counts = zero();
  appendLog = [];
  const deps: SupervisorDeps = {
    stateRoot,
    executor,
    registry,
    judge: new DeterministicJudge(),
    now: () => T0,
    generateId: sequenceGenerator(idOffset)
  };
  const start = performance.now();
  const handle = startSupervisedRun(deps, { projectRoot, objective: `cell ${name}`, tasks, limits: runLimits });
  const outcome = await handle.done;
  const ms = performance.now() - start;
  cells.push(summarize(name, outcome.status, outcome.events, handle.runId, ms));
  return { runId: handle.runId, events: outcome.events };
}

function summarize(name: string, status: string, events: readonly Event[], parentRunId: RunId, ms: number): Cell {
  const parentEvents = appendLog.filter((entry) => entry.runId === parentRunId);
  const childAppends = appendLog.length - parentEvents.length;
  const statusPath = events
    .filter((e) => e.type === "TASK_STATUS_CHANGED")
    .map((e) => `${(e.payload as { status: string }).status}@${(e.payload as { attempt: number }).attempt}`)
    .join(">");
  const verdicts = events
    .filter((e) => e.type === "JUDGE_DECISION")
    .map((e) => (e.payload as { verdict: string }).verdict)
    .join(",");
  const terminal = events
    .filter((e) => ["RUN_COMPLETED", "RUN_FAILED", "RUN_BLOCKED", "RUN_CANCEL_REQUESTED"].includes(e.type))
    .map((e) => e.type)
    .join(",");
  return {
    name,
    status,
    rounds: events.filter((e) => e.type === "LEDGER_UPDATED").length,
    taskStatusPath: statusPath,
    parentTerminal: terminal,
    ops: { ...counts },
    parentAppends: parentEvents.length,
    childAppends,
    judgeVerdicts: verdicts,
    retries: appendLog.filter((entry) => entry.type === "TASK_RETRY").length,
    leaseExpired: events.filter((e) => e.type === "TASK_LEASE_EXPIRED").length,
    ms
  };
}

interface MatrixOutcome {
  cells: Cell[];
  digest: string;
  reconstructUs: number;
}

async function runMatrix(): Promise<MatrixOutcome> {
  const stateRoot = mkdtempSync(join(tmpdir(), "r29g-adj-state-"));
  const projectRoot = mkdtempSync(join(tmpdir(), "r29g-adj-proj-"));
  const cells: Cell[] = [];
  let reconstructUs = 0;
  try {
    // L1 control: PASSED x SUCCESS -> APPROVED -> COMPLETED (existing-test anchor).
    const l1 = await runCell("L1 PASSED*SUCCESS 3/3", new TerminalExecutor("SUCCESS", "PASSED"), [task("a", 3)], limits(3, 3), stateRoot, projectRoot, cells, 0);

    // L2: PASSED x PARTIAL -> APPROVED -> COMPLETED (never exercised).
    await runCell("L2 PASSED*PARTIAL 3/3", new TerminalExecutor("PARTIAL", "PASSED"), [task("b", 3)], limits(3, 3), stateRoot, projectRoot, cells, 10_000);

    // L3: FAILED x FAILURE, attempts 3 = stalls 3 -> retry ladder ends BLOCKED (existing-test anchor).
    const l3 = await runCell("L3 FAILED*FAILURE 3/3", new TerminalExecutor("FAILURE", "FAILED"), [task("c", 3)], limits(3, 3), stateRoot, projectRoot, cells, 20_000);

    // L4: FAILED x FAILURE, attempts 1 < stalls 10 -> task FAILED -> run FAILED (existing-test anchor).
    await runCell("L4 FAILED*FAILURE 1/10", new TerminalExecutor("FAILURE", "FAILED"), [task("d", 1)], limits(1, 10), stateRoot, projectRoot, cells, 30_000);

    // L13: FAILED x FAILURE, attempts 2 < stalls 10 -> regime boundary: FAILED before stall budget.
    await runCell("L13 FAILED*FAILURE 2/10", new TerminalExecutor("FAILURE", "FAILED"), [task("m", 2)], limits(2, 10), stateRoot, projectRoot, cells, 40_000);

    // L5 contradiction cell: FAILED verification x SUCCESS outcome -> REJECTED verdict -> COMPLETED status.
    await runCell("L5 FAILED*SUCCESS 3/3", new TerminalExecutor("SUCCESS", "FAILED"), [task("e", 3)], limits(3, 3), stateRoot, projectRoot, cells, 50_000);

    // L6 contradiction cell: FAILED verification x CANCELLED outcome -> task CANCELLED -> run COMPLETED.
    await runCell("L6 FAILED*CANCELLED 3/3", new TerminalExecutor("CANCELLED", "FAILED"), [task("f", 3)], limits(3, 3), stateRoot, projectRoot, cells, 60_000);

    // L7/L8: UNOBSERVED verification -> NEEDS_USER_DECISION -> BLOCKED burn topology,
    // outcome-independent (SUCCESS vs FAILURE terminals).
    await runCell("L7 UNOBS*SUCCESS 3/3", new TerminalExecutor("SUCCESS", "UNOBSERVED"), [task("g", 3)], limits(3, 3), stateRoot, projectRoot, cells, 70_000);
    await runCell("L8 UNOBS*FAILURE 3/3", new TerminalExecutor("FAILURE", "UNOBSERVED"), [task("h", 3)], limits(3, 3), stateRoot, projectRoot, cells, 80_000);

    // L9: executor claims SUCCESS without a terminal TASK_RESULT.
    await runCell("L9 no-terminal 3/3", new NoTerminalExecutor(), [task("i", 3)], limits(3, 3), stateRoot, projectRoot, cells, 90_000);

    // L10: executor throws mid-stream.
    await runCell("L10 executor-throw 3/3", new ThrowingExecutor(), [task("j", 3)], limits(3, 3), stateRoot, projectRoot, cells, 100_000);

    // L11: per-attempt timeout (25 ms timer, 2 coordinator attempts) -> TIMEOUT outcome.
    await runCell("L11 timeout 2att/25ms", new HangingExecutor(), [task("k", 2, 25)], limits(2, 3), stateRoot, projectRoot, cells, 110_000);

    // L12: orphan-lease recovery on resume. Truncate L1's parent log right
    // after the first RUNNING status change (a crash while the child ran),
    // copy into a fresh state root, and resume with a PASSED executor.
    {
      const parentDir = join(stateRoot, "runtime", "runs", l1.runId);
      const lines = readFileSync(join(parentDir, "events.jsonl"), "utf8").trim().split("\n");
      const cutIndex = lines.findIndex((line) => {
        const parsed = JSON.parse(line) as { type: string; payload?: { status?: string } };
        return parsed.type === "TASK_STATUS_CHANGED" && parsed.payload?.status === "RUNNING";
      });
      if (cutIndex < 0) throw new Error("no RUNNING status change found in L1 log");
      const stateRootB = mkdtempSync(join(tmpdir(), "r29g-adj-resume-"));
      try {
        const dirB = join(stateRootB, "runtime", "runs", l1.runId);
        mkdirSync(dirB, { recursive: true });
        writeFileSync(join(dirB, "events.jsonl"), lines.slice(0, cutIndex + 1).join("\n") + "\n");

        counts = zero();
        appendLog = [];
        const deps: SupervisorDeps = {
          stateRoot: stateRootB,
          executor: new TerminalExecutor("SUCCESS", "PASSED"),
          registry,
          judge: new DeterministicJudge(),
          now: () => T0,
          generateId: sequenceGenerator(900_000)
        };
        const start = performance.now();
        const handle = resumeSupervisedRun(deps, l1.runId);
        const outcome = await handle.done;
        const ms = performance.now() - start;
        cells.push(summarize("L12 orphan-lease resume", outcome.status, outcome.events, l1.runId, ms));
      } finally {
        rmSync(stateRootB, { recursive: true, force: true });
      }
    }

    // Reconstruction compute share on a realistic terminal M2 log (L3's).
    reconstructUs = (() => {
      const events = l3.events;
      for (let i = 0; i < 200; i++) reconstructSupervisorState(events, () => Date.parse(T0));
      const start = performance.now();
      for (let i = 0; i < 2000; i++) reconstructSupervisorState(events, () => Date.parse(T0));
      return ((performance.now() - start) * 1000) / 2000;
    })();

    // Digest: everything except wall ms, temp paths normalized.
    const normalize = (raw: string): string => raw.replaceAll(stateRoot, "<STATE>").replaceAll(projectRoot, "<PROJ>");
    const hash = createHash("sha256");
    hash.update(
      normalize(
        JSON.stringify(
          cells.map((c) => ({
            name: c.name,
            status: c.status,
            rounds: c.rounds,
            taskStatusPath: c.taskStatusPath,
            parentTerminal: c.parentTerminal,
            ops: c.ops,
            parentAppends: c.parentAppends,
            childAppends: c.childAppends,
            judgeVerdicts: c.judgeVerdicts,
            leaseExpired: c.leaseExpired
          }))
        )
      )
    );
    return { cells, digest: hash.digest("hex"), reconstructUs };
  } finally {
    rmSync(stateRoot, { recursive: true, force: true });
    rmSync(projectRoot, { recursive: true, force: true });
  }
}
