## 2d. 新测量格 A：GC/分配预算（分配消除机制类的共同收口）

方法：同一 replay-faithful 语料（seed `0xb44b01`，N=2000，learned 非空
= 生产 eval 形状），PerformanceObserver('gc') 挂载，每格计时 40 批窗口，
报 GC 暂停总量/份额、scavenge/major/incremental 计数与分配流量估计
（scavenge 数 × new-space 32 MB + 净堆增量）。三次运行：

```text
gc-cell N=2000 [M=2 default, learned]: gc-pause share 14.91–15.52% | scavenges 32/40 batches, major 0 | est-alloc ≈25.9MB/batch | gc-cost 1.132–1.193ms per eval x2
gc-cell N=2000 [M=7 configured, learned]: gc-pause share 19.87–20.91% | scavenges 58–59/40 batches, major 1 | est-alloc ≈47.5–48.4MB/batch | gc-cost 2.904–3.129ms per eval x2
gc-cell N=2000 [M=10 stress, learned]: gc-pause share 23.39–24.32% | scavenges 77–79/40 batches, major 3 | est-alloc ≈61.8–64.0MB/batch | gc-cost 4.378–4.562ms per eval x2
```

三条结论：

1. **分配消除机制类获得共同预算收口**：GC 暂停 + 分配本体是该机制类
   （防御拷贝省略 S2-B-1/S8-B-4、享元/字面量 S4-B-3/S7-B-5/S9-B-3、
   memo S12-B-2/S13-B-1、spread 消除 S1-B-5/S5-B-4 等）能触碰的全部
   收益池；实测其上界为 **1.1–4.6 ms/eval**（且大部分分配是输出契约必需
   ——decision/assignment/refusal 行本身），深低于落地线一个量级。任何
   未来的分配向候选无需逐个实现即可先对照此格预算。
2. **历史符号翻转的机制性定量解释**：单次 scavenge 暂停 ~0.7–1.2 ms
   （M=10 窗内 88–91 ms ÷ 77–79 次 ≈ 1.1 ms），与 S12-B-1（±2.7 ms 端点
   为 GC 离群对）、S13-B-1（±0.5–1.1 ms 差额区间）的被淘汰候选差额同阶
   ——批窗内 ±1 次 scavenge 即翻转符号。验收线第 3 条的「符号稳定」要求
   在本切片的物理含义就是「候选差额必须显著超过一次 scavenge」，即
   ≥数 ms/批；这与落地线自洽。
3. 该格同时解释 §2b 的 M=10+learned 离群（21.91 ms）：M=10 批分配 64 MB、
   窗内 major 3 次，major/incremental 错位落入计时窗即产生 +3 ms 级
   离群——与 R12-B 的 22.21 同因。

function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

}

interface GcWindow {
  pauseMs: number;
  minor: number;
  major: number;
  incremental: number;
  other: number;
}
const gcAccumulator: GcWindow = { pauseMs: 0, minor: 0, major: 0, incremental: 0, other: 0 };
const gcObserver = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    gcAccumulator.pauseMs += entry.duration;
    const kind = (entry as unknown as { detail?: { kind?: number } }).detail?.kind;
    if (kind === perfConstants.NODE_PERFORMANCE_GC_MINOR) gcAccumulator.minor += 1;
    else if (kind === perfConstants.NODE_PERFORMANCE_GC_MAJOR) gcAccumulator.major += 1;
    else if (kind === perfConstants.NODE_PERFORMANCE_GC_INCREMENTAL) gcAccumulator.incremental += 1;
    else gcAccumulator.other += 1;
  }
});
gcObserver.observe({ entryTypes: ["gc"] });
async function flushGcEntries(): Promise<void> {
  await new Promise((resolve) => setImmediate(resolve));
  await new Promise((resolve) => setImmediate(resolve));
}
function snapshotGc(): GcWindow {
  return { ...gcAccumulator };
}
function diffGc(before: GcWindow): GcWindow {
  return {
    pauseMs: gcAccumulator.pauseMs - before.pauseMs,
    minor: gcAccumulator.minor - before.minor,
    major: gcAccumulator.major - before.major,
    incremental: gcAccumulator.incremental - before.incremental,
    other: gcAccumulator.other - before.other
  };
}

function describeStatus(status: number): string {
  const bits: string[] = [];
  if (status & (1 << 1)) bits.push("never-optimize");
  if (status & (1 << 3)) bits.push("maybe-deopted");
  if (status & (1 << 4)) bits.push("optimized");
  if (status & (1 << 5)) bits.push("maglevved");
  if (status & (1 << 6)) bits.push("turbofanned");
  if (status & (1 << 7)) bits.push("interpreted");
  if (status & (1 << 8)) bits.push("marked-for-opt");
  if (status & (1 << 14)) bits.push("marked-for-deopt");
  if (status & (1 << 15)) bits.push("baseline");
  return `${bits.join("+") || "none"} (raw=${status})`;
}

  catalog: ModelRouterConfig,
  learned: LearnedRoutingPolicy | undefined,
  batches: number
): Promise<void> {
  const replayTasks = genReplayTasks(mulberry32(0xb44b01), 2000);
  const run = (): void => {
    assignTasks({ catalog, tasks: replayTasks, ...(learned !== undefined ? { learned } : {}) });
  };
  run();
  run();
  if (maybeGc !== undefined) maybeGc();
  await flushGcEntries();
  const newSpace = v8.getHeapSpaceStatistics().find((space) => space.space_name === "new_space");
  const newSpaceMb = (newSpace?.space_size ?? 0) / (1024 * 1024);
  const heapBefore = process.memoryUsage().heapUsed;
  const before = snapshotGc();
  const t0 = performance.now();
  for (let i = 0; i < batches; i += 1) run();
  const windowMs = performance.now() - t0;
  await flushGcEntries();
  const gc = diffGc(before);
  const heapDeltaMb = (process.memoryUsage().heapUsed - heapBefore) / (1024 * 1024);
  const estAllocMb = gc.minor * newSpaceMb + Math.max(0, heapDeltaMb);
  const sharePct = (gc.pauseMs / windowMs) * 100;
  console.log(
    `gc-cell N=2000 [${label}]: window=${windowMs.toFixed(1)}ms/${batches} batches | gc-pause=${gc.pauseMs.toFixed(2)}ms (${sharePct.toFixed(2)}%) | scavenges=${gc.minor} major=${gc.major} incr=${gc.incremental} | est-alloc≈${(estAllocMb / batches).toFixed(1)}MB/batch (new-space=${newSpaceMb.toFixed(1)}MB) | gc-cost≈${((gc.pauseMs / batches) * 2).toFixed(3)}ms per eval x2`
  );
  if (label === "M=10 stress, learned") {
    conclusions.push(
      `gc-budget M=10+learned pause-share=${sharePct.toFixed(2)}% gc-per-eval=${((gc.pauseMs / batches) * 2).toFixed(3)}ms (allocation-channel-below-landing-line=${(gc.pauseMs / batches) * 2 < 30})`
    );
  }
}
