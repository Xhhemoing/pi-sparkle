## §2 新轴：运行限额剩余配置面 / 预算携带 × 命令类（RUNLIM，战役首创）

### 2.0 为什么这是 R1-G…R23-G 从未拉伸的完备格

R7-I 教训的本轮应用：`FlowchartRunLimits` 的五个旋钮里，历轮矩阵与
全部专轴只把 `maxConcurrentNodes`（SCHEDWIN：verb 计数剖面 =

T4 stall 终态腿）当过被扫变量；`remainingTimeMs` / `remainingCostUsd`

全文 grep：前两者零出现 / 仅夹具填充。但该面不是死代码：

- **携带链**（§0 已列行号）每 lease 组装 `routingLimits()`、每决策
  `consumeRoute()` 扣减、每 persist 进 snapshot 并过双层校验闸、
  resume 时经 `limitsFromSnapshot` 恢复——默认态下 `remainingTimeMs`
  腿**常开**（从 MAX_SAFE_INTEGER 起扣），`remainingCostUsd` 腿仅在
  配置时展开（undefined 分支跳过），`minHumanConfidence` 进路由入参
  校验与注入决策策略（flowchart-run.ts:1088）。
- **预算耗尽终端**是独立语义类：live-selection.ts:58 的拒绝消息在
  flowchart-supervisor.ts:695-698 被 lease 循环捕获置节点 FAILED——
  TERMCLASS 六终态类里的 FAILED 全部由 child FAILURE 结局驱动，
  预算类 FAILED 从未被真跑过。
- **检查点字段在位格**：CKMIX（R23-G）扫过 run/project 单例、五种群、
  decisions、pendingApproval 等在位维，但 `remainingCostUsd` 在
  snapshot+limits 的在位格当轮不在扫描集内（B0 锚默认限额恒缺位）。

三个从未定价的自由度（配置腿单价、预算终端形状、预算字段在位）

          const dir = join(stateRoot, "runtime", "runs", outcome.runId);
          const normalize = (raw: string): string =>
            raw.replaceAll(stateRoot, "<STATE>").replaceAll(projectRoot, "<PROJ>")
              .replace(/\d{4}-\d{2}-\d{2}T[0-9:.]+(Z|[+-]\d{2}:\d{2})/g, "<T>");

            createHash("sha256").update(normalize(eventsRaw)).update(normalize(checkpointRaw)).digest("hex")
          );

              `limits.H=${JSON.stringify(limits.minHumanConfidence)}`,
            failedReason: failed !== undefined ? String((failed.payload as { reason?: string }).reason) : "-",
            wallMs: 0,
            bytes: checkpointRaw.length
          };
        } finally {
          rmSync(stateRoot, { recursive: true, force: true });
        }
      }
      const stable = digests.every((d) => d === digests[0]);
      out!.wallMs = walls.sort((a, b) => a - b)[Math.floor(walls.length / 2)]!;
      if (out!.status !== drive.expectStatus) throw new Error(`${drive.name}: status ${out!.status} != ${drive.expectStatus}`);
      if (!stable) throw new Error(`${drive.name}: unstable artifacts`);
      witness(`  ${drive.name}: status=${out!.status} digest=${digests[0]!.slice(0, 16)}... rep-stable=yes`);
      witness(`    events [${out!.eventTypes}]`);

      witness(`    carry ${out!.budgetCarry}`);
      witness(`    failedReason ${out!.failedReason}`);
      console.log(`    wall median ${out!.wallMs.toFixed(1)} ms`);
      driveOuts.push(out!);

    })();

    if (!Object.is(gotCmid, expectCmid)) throw new Error("EXH-Cmid carry arithmetic mismatch");

    /* REJ-NEG: fail-closed reject in resolveLimits before any I/O */
    {
      const stateRoot = mkdtempSync(join(tmpdir(), "r24g-runlim-rej-"));
      try {
        resetCounts();
        const started = performance.now();
        let message = "NO-THROW";
        try {
          await startFlowchartRun(
            { stateRoot, router: router(), now: () => T0, generateId: sequenceGenerator("9") },
            { projectRoot, flowchart: chainFlowchart(), limits: { remainingCostUsd: -1 } }
          );
        } catch (error) {
          message = (error as Error).message;
        }
        const rejectUs = (performance.now() - started) * 1000;
        witness(`  REJ-NEG: throw "${message}" ioCounts ev.app ${ioCounts.evAppend} / cp.w ${ioCounts.cpWrite}`);
        console.log(`    reject wall ${rejectUs.toFixed(1)} us (once-per-command reject class)`);
        if (message === "NO-THROW" || ioCounts.evAppend !== 0 || ioCounts.cpWrite !== 0) {
          throw new Error("REJ-NEG must fail closed before any I/O");
        }
      } finally {
        rmSync(stateRoot, { recursive: true, force: true });
      }
    }
  } finally {

  }
