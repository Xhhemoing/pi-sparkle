### 2.1 轴定义与战役首创性（非重铸论证）

**受控变量**：切片持久工件**钉死规范路径到承载钉死规范字节的 inode
之间的文件系统绑定结构**：

- **D** 直接普通文件（对照——二十九轮每一个夹具家族唯一铸过的
  绑定）；
- **LF** 文件级符号链接（规范路径是符号链接 → 兄弟 `.targets/`
  目录下的普通文件）；
- **LD** 父目录符号链接（工件父目录是符号链接 → 他处真实目录，
  文件本体为普通文件）；
- **H** 硬链接（规范路径是同一 inode 的两个名字之一，nlink=2，
  备用名在兄弟 `.alt/` 目录）；
- **L8** 8 级符号链接链（规范路径 → c1 → … → c7 → 目标——本面
  自带的量级坐标：逐跳解析成本）。

**二十九轮从未受控的证据**（逐报告核对）：历轮全部夹具经生产写手
（`writeFeedbackRecords` / `appendJsonlLine` / `saveToDisk` / 级联
侧车写手——R13-J 普查的动词集 writeFile/appendFile/mkdir **只能产
直接普通文件**）或逐字节复刻铸造，全部落在 D 绑定；ZREP 的 F/C/E
臂、CSPELL 的全部拼写臂、SIDEC/DELINV 的全部量级臂无一例外。切片
29 文件 grep 零链接动词（`symlink|linkSync|link\(|realpath|lstat`
全库仅命中切片外 `src/project/discovery.ts` 一处）⇒ **战役首创**。
外来绑定在生产中可达：三个工件都在用户 state root 下
（record-classes.ts L92/L104 契约证词），用户以符号链接把 state
子树重定位到他盘/他目录（常见磁盘管理动作）、或以硬链接建立备份
别名，读缝与写缝全额接受且写透（W-1/W-2/W-4 见证）。

**与已闭轴的区分**：非 R28-I（路径名字文本 vs 名字之下的

### 2.4 裁决

五腿全部「无候选」，三重收口：

1. **生产只能铸最便宜绑定，外来绑定不是自由变量**：三个同号税
   （LF 水合税、LF 删除税；LD 为负无税）全部挂在**外来**绑定臂上，
   而 D 臂是仓内写手动词唯一能产出的绑定（R13-J 动词普查 +
   本轮切片零链接动词 grep 直证）；外来绑定仅能由外部磁盘管理
   动作铸入，且铸入后生产动词全部写透保留（W-2/W-4）、删除动词
   解除名字（W-8）——「让读缝更快」没有生产侧剩余动作，「让外来
   绑定更快」的收益上界即 +9~19 µs/命令且外来绑定非仓库属地。
2. **全部代码侧改形撞已闭族**：读时 realpath 归一/解析缓存 =
   X1-1（多进程外部改写 + 陈旧缓存）；读缝拒链接（O_NOFOLLOW /
   lstat 卫）= 接受包络收窄的**行为变更**——用户合法的符号链接
   重定位布局（今天写透可用，Leg P LD 甚至更快）会被打破，且这是
   健壮性/安全域动作而非保行为优化；删除时沿链追杀指称目标 =
   行为变更 + 指称可在 state root 之外（危险动作，as-built 的
   「解除名字」语义正确且已由 record-classes.ts delete-files
   策略措辞覆盖——删除的是 state-root 名下的记录）；fs API 换形
   （open+fstat 组合等）= R13-J 已闭。
3. **量级**：LF 水合税 +8.9~+10.1 µs × 每 pref 命令一次 / LF 删除
   税 +15.9~+18.9 µs × 每删除命令一次——once-per-command µs 拒收
   类，距落地线 3 个数量级；本面自带量级坐标（链长）被直接定价：
   L8 的 8 跳在读缝上**低于测量地板**（两轮最快臂），且内核以
   ~40 链 ELOOP 硬顶封界、越顶在读缝 fail-closed（W-7a）——把
   解析税推到可测量级在包络内不存在。

五条语义普查事实随轴入档（proposal-first，仅观察不改产码；见结论
(a)–(e)）：重写动词写透绑定从不替换（剥 body 经符号链接/硬链接
全额传播——隐私正向）；删除动词解除规范名字不追指称（外部别名在
删除契约域外存活——as-built 普查）；ELOOP 跨缝不对称（readFeedback
抛 / 级联吞——吞取端点本体 R18-J 已定价，新增错误来源类对比）；
悬空链接名在态缺 + 写动词物化指称；偏好店 ELOOP configure 半态
（existsSync 吞解析错误）。按纪律不铸任何 S30-J-\* ID；LINKTOP
只入本报告、不写 EXCLUSIONS 行（父代理计划禁令域）。完备性洞已补：
