## 2. 本轮实扫新轴 + 第二十二组新角度枚举：有理由的空枚举

### 2.0 新轴 NVG：数值值类面（本切片首次；score 值类 N × bandit 计数幅值 K-mag）

R1-E..R21-E 的十四个维度没有任何一维变动过「流经切片的数值是什么
类别的数」。E 切片的数值消费面：diagnose 的 score 求和/除法/两处
比较（`diagnostics:36-41`，48 次/富夹具）、`score<40`/`score>=50`
分界（`signals:185/350`）、bandit pulls/rewardSum 复制与 `+1/+0`
累加（`bandit-store:55-77`，实现体 B 辖区）、fbk\_ 铸造的
`${signal.score}` 数→串（`auto-loop:207`）、reason 模板的
`meanScore.toFixed(2)`（`auto-loop:141`）、`Number.isFinite` 校验
（`signals:78`）。而二十一轮夹具与切片内全部生产写入方的 score
恒为 SMI 整数——值类维度从未定价。本轮四档 N 剂量 + 三格 K-mag
剂量定价（6 次全剂量 + 8 次单剂量隔离运行，sanity 全绿；数字见
结论 1–3，此处不重抄），关键机制事实与裁决：

- **N 剂量平坦性的机制**：V8 对小整数用 SMI 标记指针、对小数用堆
  双精度/非装箱双字段；diagnose 的 reduce 求和在首个双精度加数后
  整段走双精度加法，`<40`/`<0.45` 比较两类同速；score 从不作键。
  实测富夹具（48 次 score 消费）全档全趟 8865–9414 ns 无相干斜率
  ——**值类不是该切片任何热路径的成本项**。混流档（N2）证实
  SMI/double 交替也不产生可测的形状/PIC 搅动税（与 S8-E-2 的 PIC
  敏感项记录相容：那是字段**有无**维度，本轴是字段**值类**维度）。
- **夹具保真度先天成立**：与 IDG（夹具短 id vs 生产 40ch id 有
  缺口需实测对齐）不同，NVG 域分析显示切片内写入方只发整数字面量
  {10,15,20,25,45,50,65,70,85,90}——夹具值类 = 生产值类，二十一轮
  锚点在值类维度上无任何低估可能；唯一非 SMI 入口
  （parseObservedSignal，仅 `Number.isFinite` 卫）本轮首手复核零
  生产写入方（§1 矩阵新列）。schema 合法但零流量的双精度门本身也
  实测平坦——双保险收口。
- **fbk\_ 铸造数→串斜率不存在**：单剂量隔离进程实测 N0（SMI 72）
  与 N1（72.25）的 mint 带完全重叠（1088–1405 vs 1063–1376 ns），
  趟内位置噪声支配；R21-E 已证支配项是 hash32 吃 400ch summary，
  本轮补全数值侧：`${score}` 的 SMI 快路径 vs 双精度 DtoA 差异在
  该表达式内不可测。该位点 I/O 支配（appendFeedback 追加在后）+
  fbk id 内容散列语义是数据面契约（R21-E 同判），双重拒列维持。
- **K-mag 平坦性与可达性**：pulls/rewardSum 幅值三格 793–992 ns
  平坦；SMI 顶（2³¹）需 ~2.1×10⁹ 次 taskSuccess 奖励——每 run 至多
  个位数 outcomes，生产不可达；双精度类 rewardSum 只能来自被篡改的
  bandit.json（advisory 面 fail-soft，R20-E C4 谱系）。实现体
  `createBanditState`/`recordReward` 在 `src/routing/bandit.ts`
  （B 辖区），E 内仅持调用边与 S2-E-3 参照复制体。
- **唯一相干斜率在域缘**：`toFixed(2)` 对 meanScore≈1e13 比对
  0.18 贵 +15–25 ns（77–99 vs 61–74 ns）——需要 1e15 级 score 进入
  diagnose（零流量入口 + 零生产写入方），且该模板每 failing issue
  至多一次/run。深度亚噪声 + 双重不可达，不铸 ID。

**裁决**：该轴在频率（值类不改变调用频次；非 SMI 入口流量恒零）×
单价（域内全档平坦、域缘斜率 +15–25 ns 距落地线 5 个量级）× 属地
（mint 数据面契约 + I/O 支配；bandit 幅值 B 辖区；校验补强 X0-2 族）
三端封死，**不产生候选**。「数值值类」维度就此与前十四维正交封口：
成本 = f(构成)，与数值类别、数值幅值解耦——「构成 × 键几何 ×
值类」三因子化完成。
