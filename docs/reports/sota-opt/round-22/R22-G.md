## §2 新轴：终态类 × 命令类补全（TERMCLASS，战役首创）

**为什么是新的**：R21-G 收口时把每 run 地板因式分解
floor = Σ 动词计数(width, W) × 动词单价(计数/设备/字节/路径名 |
进程环境) 的两个因子宣告扫毕——但该分解的**定义域**一直只覆盖成功形
终态：14 格矩阵（本轮附录 A 复跑原表可查）的状态列是 fresh → COMPLETED
/ WAITING / PAUSED / CANCELLED，SCHEDWIN 的 15 格全部 start→COMPLETED，
XPROC 车队亦然。FAILED / BLOCKED 两类终态从未被真实驱动过一次：失败
裁决、失败被接（恢复边）、停滞耗尽、maxRounds 耗尽四条**生产可达**
路径的 I/O 计数剖面是未测的（FAILED 是普通结局——任何 child 失败即达；
BLOCKED 是 stall 保护的正常出口），两个新状态对四个命令类的行为与
价格也是未测的（BLOCKED 可 inject / 可 resume 续跑，FAILED 一律终态
——这是与已测四状态不同的合法性矩阵）。R17-G 的 REJECT-PRICE 与此
**不同轴**：那是校验器 throw 位点的 µs 级拒绝定价（稳态流量零）；
本轴驱动的是**不抛错的合法命令结局**（RUN_FAILED / RUN_BLOCKED 事件
被正常追加、检查点被正常落盘、episode 被正常结算），两个非法格
（pause/inject@FAILED 类）仅作合法性普查见证，沿用矩阵 C9/C10 先例。
该轴一次性回答：(a) 失败/停滞路径有无隐藏的超线性或额外 I/O 病理
（重试、级联重读）；(b) 停滞记账是否精确（若不精确 = 伪装成优化空间
的 bug）；(c) 新状态上的命令价格是否落在已裁决动词栈内。

**方法**（驱动全文见附录 B；正式三批 seed 0xa22081/82/83 + 冒烟批
0xa22080，四批逐字节同码。固定时钟 + 每格重启的顺序 id，确定性构造；
seed 仅标注批次；全程默认窗口 W=4——与 SCHEDWIN 无叉积）：

- **A 部：终态类驱动**（真实 `startFlowchartRun`，每驱动 5 重复，
  新鲜 mkdtemp 状态根，原型插桩计数）：T1 `completed` 链 a→b→c 全
  SUCCESS（对照 = 矩阵 C1 同形）；T2 `failed-verdict` 同链 b 给
  FAILURE（c 不可达 → SKIPPED → FAILED）；T3 `failed-handled`
  a→b→c 成功脊 + b→r `success:false` 恢复边，b FAILURE、r SUCCESS
  （→ COMPLETED）；T4 `blocked-stall` 链 a→b 只给 a 结果（b 领租后
  饿死 → 停滞 1,2,3 → BLOCKED）；T5 `failed-maxrounds` 同 T4 但
  maxRounds=2（先于停滞阈值耗尽 → FAILED）。
- **B 部：命令格**（每格 5 重复，每重复新鲜前驱 run，计数在前驱
  之后清零）：inspect / resume(noop) 于 FAILED 与 BLOCKED；
  resume(results) 于 BLOCKED（补给 b 结果）；inject(fact) 于
  BLOCKED（合法）与 FAILED（非法）；pause 于 FAILED / BLOCKED
  （均非法）。
- **等价见证**：(1) 每格 5 重复计数剖面逐位相同；(2) 事件级事实
  精确成立（T2 reason、T4 停滞记账与 RUN_BLOCKED 恰一次、T3 终态
  节点映射、T5 reason、episode 结算分派、resume(noop)@BLOCKED 不得
  追加第二条 RUN_BLOCKED、resume(results)@BLOCKED 必须恢复到
  COMPLETED、非法格精确消息）；(3) 14 格归一化工件摘要跨批逐位一致。

const normalizeWith = (stateRoot: string, projectRoot: string) => (raw: string): string =>
  raw.replaceAll(stateRoot, "<STATE>").replaceAll(projectRoot, "<PROJ>")
    .replace(/\d{4}-\d{2}-\d{2}T[0-9:.]+(Z|[+-]\d{2}:\d{2})/g, "<T>");

async function artifactDigest(stateRoot: string, projectRoot: string, runIds: readonly RunId[]): Promise<string> {
  const normalize = normalizeWith(stateRoot, projectRoot);
  const hash = createHash("sha256");
  for (const rid of runIds) {
    const dir = join(stateRoot, "runtime", "runs", rid);
    hash.update(normalize(await readFile(join(dir, "events.jsonl"), "utf8")));
    hash.update(normalize(await readFile(join(dir, "checkpoint.json"), "utf8")));
  }
  return hash.digest("hex");
}

function eventFacts(events: readonly Event[]): {
  runFailedReasons: string[]; runBlocked: number; stallDetected: Array<{ round: number; consecutiveStalls: number }>;
  episodeClosed: string[]; episodeWaiting: string[]; runCompleted: number;
} {
  const runFailedReasons: string[] = [];
  const stallDetected: Array<{ round: number; consecutiveStalls: number }> = [];
  const episodeClosed: string[] = [];
  const episodeWaiting: string[] = [];
  let runBlocked = 0;
  let runCompleted = 0;
  for (const event of events) {
    if (event.type === "RUN_FAILED") runFailedReasons.push((event.payload as { reason: string }).reason);
    else if (event.type === "RUN_BLOCKED") runBlocked += 1;
    else if (event.type === "RUN_COMPLETED") runCompleted += 1;
    else if (event.type === "STALL_DETECTED") {
      const p = event.payload as { round: number; consecutiveStalls: number };
      stallDetected.push({ round: p.round, consecutiveStalls: p.consecutiveStalls });
    } else if (event.type === "EPISODE_CLOSED") episodeClosed.push((event.payload as { status: string }).status);
    else if (event.type === "EPISODE_WAITING") episodeWaiting.push((event.payload as { reason: string }).reason);
  }
  return { runFailedReasons, runBlocked, stallDetected, episodeClosed, episodeWaiting, runCompleted };
}
