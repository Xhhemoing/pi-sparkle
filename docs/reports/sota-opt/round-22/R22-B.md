## 1. 第二十二遍搜索方法：标识符几何透镜（模型 id 字节长 G × taskId 字节长 T）

R1-B「输出契约渐近下界」…R17-B「路径完备性」、R18-B「输入基底/配置完备性」、
R19-B「决策序/规模矩形完备性」、R20-B「规模立方 L 边 + 约束双线性 K×W」、
R21-B「prior 快照形状 R×A」。源码枚举空间（R12-B 12×19 叉积）、输入/目录/
prior/learned 形状与规模、引擎运行态与代际、站点份额与字符串基底、拒绝路径
与尾部、比较器腿与 {N,M,L} 立方、K×W 乘积项、prior 自身 R×A 全部清点后，
切片入口的**字符串字节基数**只剩标识符本身：

1. **G 主轴（§2d）**：模型 id 贯穿六类站点（per-route Set 构造、trim 校验、
   unknown 哈希扫、preferred 等值比较、localeCompare tie 腿、决策对象三处
   模板 + oneHot 键）。二十一轮夹具 id 恒 2–13 字符。契约无顶（§0 取证）。
   理论上有两种可能形态：线性（如 L 轴——那么 S12-B-1 等全族裁决需按
   G 重定价）或平坦（V8 三机制：哈希缓存 + 边界 trim + cons 串——那么
   全族裁决获得比原文更强的地基）。必须实测分辨，两个形态都必须配保真
   断言（pad 前缀构造保序，strip-pad 逐字节等于基线）。
2. **T 副轴（§2d）**：taskId 只流经一处模板（makeApprovalPlan
   `approval:${taskId}:${model.id}`，model-router.ts:191）+ 决策回显
   （指针拷贝）。契约硬顶 68 字符（ids.ts:51 结构性封顶，R20-B roles

3. **归因三腿（§2d 微探针）**：(a) 同对象 Set（哈希缓存）vs 新等值串 Set

   到底谁付」的账目落到切片外的下游序列化面。
4. **换名识别透镜**：枚举中冒出的其余想法逐一对表（§4.3），全部识别为

/* ============================================================

 * asserted for the real face (every arm) and the N=2000 replay (P=64 arm).
 * Arms:
 *   G axis (M=7 configured + learned, taskId at base 10 chars):

 *     (a) new Set(ids) with the SAME string objects the batch reuses
 *         (V8 caches the string hash -> length-independent steady state)
 *         vs FRESH equal strings (uncached hash pays TH(G) once per string);
 *     (b) per-id trim() scan (validateInput's per-route term).
 *   Deferred-flattening probe: JSON.stringify of the N=30 assignment batch

  const baseReplay = JSON.stringify(assignTasks({ catalog: catalogCfg, tasks: replayTasks, learned }));

  function padded(pad: string): { catalog: ModelRouterConfig; learned: LearnedRoutingPolicy } {
    return {
      catalog: {
        ...catalogCfg,
        models: catalogCfg.models.map((model) => ({ ...model, id: pad + model.id }))
      },

        primaryModelId: pad + learned.primaryModelId,
        avoid: learned.avoid.map((row) => ({ ...row, modelId: pad + row.modelId })),

        `id-geometry REAL face crossing [G]: slope=${slopeUsPerChar.toFixed(4)}us/char*batch -- indistinguishable from zero, no crossing in any reachable regime`
      );
    }
    conclusions.push(
      `id-geometry G: FLAT -- replay per-eval pad=0 ${(r0 * 2).toFixed(1)}ms -> pad=4096 ${(r4096 * 2).toFixed(2)}ms (${(r4096 / r0).toFixed(3)}x across 2 orders of magnitude; slopes ${slopeLow.toFixed(3)}/${slopeHigh.toFixed(3)}ns/char*task at noise); live face pad=0 ${(f0 * 1e3).toFixed(1)}us -> pad=4096 ${(f4096 * 1e3).toFixed(1)}us (production G band 5-40 chars)`

    let sink = 0;

    }, 500);

      sink += JSON.stringify(fatAssignments).length;

      { label: "T=4102 SCHEMA-UNREACHABLE", suffix: 4098, reps: 20, inContract: false }
