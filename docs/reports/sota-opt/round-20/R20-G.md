## §2 新轴：跨进程干涉定价（XPROC，战役首创）

**为什么是新的**：R19-G 收口时声明动词价格函数
f(调用数, 设备, 负载字节, 路径名) 「不再有任何未测输入」——该声明对
**进程内**输入成立，但前十九轮全部测量共享同一个隐含条件：**单进程、
串行、无外部并发**。而并发在域上是真实自由度：(a) pause / inspect /
cancel 是产品设计上**从第二个进程**打到在跑 run 的命令面（矩阵 C11
格「cancel(x-process append)」正是跨进程语义的存证）；(b) 同一状态根
上多个 `run` 命令并行是合法用法；(c) run 面存储**刻意无锁**（对照
adaptation 面的文件锁），其并发正确性依赖 O_APPEND 前缀原子性 +
截尾恢复协议 + rename 原子替换——这套契约在战役中从未被真实并发
压测过。R20-D 的多进程轴定价的是 adaptation 面**锁**争用（bandit
锁阶梯、eval 车队、陈旧锁超时），G 属地无锁 run 面一个动词都没碰
——本轴恰为派单预留的「G-owned site those D measurements never
priced」。该轴一次性回答：外部并发会不会改变已裁决的动词价格（若会，
「隔离/加锁/攒批」假设族是否有落地空间）、无锁契约在真实并发下是否
成立（语义面）。

**方法**（驱动全文见附录 B；3 正式批 seed 0xa20081/82/83 + 冒烟批
0xa20080 复核复现性。固定时钟 + 顺序 id，确定性构造；seed 仅标注
批次。4 核 VM：R 阶梯设计为写者 + 3 读者 = 恰满核不超订；F=8 刻意
2:1 超订为最坏车队条件）：

- **A. 独跑对照 rung（R=0）**：新鲜状态根上按重锚协议测 append(400)
  / cp.write(150)（驱动内自带基线，不跨批比较）。
- **B. 读者干涉阶梯**：目标 run 预置 300 事件日志 + N=48 检查点；
  R ∈ {1, 3} 个子进程紧循环 `EventStore.readAll()`（真实逐事件
  validate）锤击**同一** events.jsonl，主进程同时测 append(400) +

async function readerRung(label: string, R: number, neighbor: boolean): Promise<RungOut> {
  const root = mkdtempSync(join(tmpdir(), `r20g-xproc-b-`));
  const workFiles: string[] = [];
  const procs: ReturnType<typeof spawn>[] = [];
  const stopFile = join(root, "stop.flag");
  try {
    const store = new EventStore(root, TARGET_RUN);
    for (let i = 0; i < 300; i++) await store.append(agentEvent(i, TARGET_RUN));
    const ckStore = new CheckpointStore(root, TARGET_RUN);
    await ckStore.write(checkpoint48);
    if (neighbor) {
      const nStore = new EventStore(root, NEIGHBOR_RUN);
      for (let i = 0; i < 300; i++) await nStore.append(agentEvent(i, NEIGHBOR_RUN));
    }
    const readRun = neighbor ? NEIGHBOR_RUN : TARGET_RUN;
    for (let r = 0; r < R; r++) {
      const outFile = join(root, `reader-${r}.json`);
      workFiles.push(outFile);
      procs.push(spawnChild(["reader", root, readRun, stopFile, outFile]));
    }
    if (R > 0) await waitFor(() => workFiles.every((f) => existsSync(`${f}.ready`)), 30_000, `${label} readers ready`);
    let n = 10_000;
    const appendUs = await benchAsync(`  [${label}] append`, 400, async () => { await store.append(agentEvent(n++, TARGET_RUN)); });
    const ckUs = await benchAsync(`  [${label}] cp.write(N=48)`, 150, async () => { await ckStore.write(checkpoint48); });
    writeFileSync(stopFile, "1");
    if (R > 0) await waitFor(() => workFiles.every((f) => existsSync(f)), 30_000, `${label} reader outputs`);
    const readers: unknown[] = [];
    for (const f of workFiles) readers.push(JSON.parse(await readFile(f, "utf8")));
    const final = await store.readAll();
    const finalDigest = createHash("sha256").update(JSON.stringify(final.events)).digest("hex");
    for (const r of readers) {
      const s = r as { count: number; recoveries: number; corrupt: number; mono: number; maxEv: number; meanUs: number };
      console.log(`    reader: reads=${s.count} recoveries=${s.recoveries} corrupt=${s.corrupt} mono-violations=${s.mono} maxEvents=${s.maxEv} mean=${s.meanUs.toFixed(1)} us/read`);
    }
    console.log(`    final readAll digest: ${finalDigest.slice(0, 16)}... (${final.events.length} events)`);
    return { appendUs, ckUs, finalDigest, readers };
  } finally {
    for (const p of procs) p.kill("SIGKILL");
    rmSync(root, { recursive: true, force: true });
  }
}
