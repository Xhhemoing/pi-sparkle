## §2 新轴：名字空间/路径形状分解（NAMESHAPE，战役首创）

**为什么是新的**：把每个 I/O 契约动词的价格写成函数
f(调用数, 设备, 负载字节, 路径名)——R16-G 用 ptrace 普查把**调用数**
维度封死（无隐藏可删动词）；R17-G 用 overlay/tmpfs 对拍把**设备**维度
封死（物理极限 6.0–7.4 ms）；R18-G 用字节梯 + 宽度扫把**负载字节**
维度封死（地板即固定价）。但**路径名**输入从未被变动过：前十八轮全部
测量都用同一几何（mkdtemp 基底 + `runtime/runs/<runId>/events.jsonl`，
6 组件 62 B ASCII）。而路径名在域上是真实自由度——stateRoot 由用户
项目位置决定（任意深/长/宽字符），`runtime/runs/` 目录随项目生命期
积累 run 目录（无修剪逻辑，扇出无界）。该轴一次性回答：「重构状态根
布局 / 缩短嵌套 / 短 id / 修剪存量目录」——任何改路径名不改信息的
假设——能否触及数十 ms 落地线；顺带把 R16-G 计数层的 K≤88 规模平坦
结论延伸到 10⁴ 扇出的**价格层**。

**方法**（驱动全文见附录 B；正式六批 = 协议 v1 三批 seed
0xa19081/82/83 + 协议 v2 三批 seed 0xa19084/85/86，v2 仅在扇出梯每阶
测量前增加 `sync` 冲刷（分离脏元数据条件），A/B/D/E 部分两协议逐字节
同码；另一冒烟批 0xa19087 复核复现性。固定时钟 + 顺序 id，确定性
构造；seed 仅标注批次）：

- **A. 深度梯**：state root 嵌套 +0/+8/+32/+64 个 8 B 组件（绝对路径
  6/14/38/70 组件，62–638 B）；每阶测 EventStore.append（400 次）、
  EventStore.readAll（300 事件日志，100 次）、CheckpointStore.write
  （真实 N=48 检查点 30 KiB，150 次），对组件数最小二乘拟合。
- **B. 组件长度/宽度梯**：固定 +8 深度，组件 4/60/200 B ASCII（路径
  102/550/1,670 B）拟合 µs/KiB-of-path；再以字节对齐 CJK 组件
  （`验`×20 = 60 B）对拍 60 B ASCII 阶（宽度探针，镜像 R18-G 负载
  宽度扫到名字空间维度）。
- **C. 同辈扇出梯**：单一 state root，`runtime/runs/` 下预建 1 /
  1,001 / 10,001 个同辈 run 目录（各含真实一行 events.jsonl）；每阶
  对同一目标 run 测三动词 + statx 探针；v2 在每阶测量前 `sync` 冲刷
  新建元数据（稳态条件），v1 不冲刷（脏条件对照）。
- **D. 裸名字空间操作归因**：每阶测 statx / open+close / mkdir-EEXIST
  （后者是每 append 与每 cp.write 必付的 ensure-dir 操作，S5-G-1 族）
  各 400 次，拟合 ns/组件，归因 A 部斜率。
- **E. 运行级算术**：以 R16-G SYSCENSUS 路径行走动词计数（openat 49 +
  statx 47 + mkdir 27 + access 14 + rename 8 = 145/run）× 拟合斜率，
  界定名字空间份额与「拍平布局」假设上界。
- **等价见证**：全部阶用同一 runId 与同一事件流；每阶 readAll 结果全
  事件数组 sha256 必须跨阶逐位一致（路径几何信息无关性证明）。

/* Least-squares linear fit: cost_us = fixed + slope * x */
function fit(points: Array<{ x: number; us: number }>): { fixed: number; slope: number } {
  const n = points.length;
  const sx = points.reduce((a, p) => a + p.x, 0);
  const sy = points.reduce((a, p) => a + p.us, 0);
  const sxx = points.reduce((a, p) => a + p.x * p.x, 0);
  const sxy = points.reduce((a, p) => a + p.x * p.us, 0);
  const slope = (n * sxy - sx * sy) / (n * sxx - sx * sx);
  return { fixed: (sy - slope * sx) / n, slope };
}

    for (let i = 0; i < 8; i++) root = join(root, comp);

}

/* ---- Part C: sibling fan-out ladder ----------------------------------------- */
console.log("\n[C] sibling fan-out ladder under runtime/runs/: 1 / 1,001 / 10,001 dirs");

    }

    results.push(r);
    fanRungs.push(r);
    /* remove the measured run dirs so the next rung re-measures cleanly at

    for (const id of [RUN_APP, RUN_RDA, RUN_CKP]) rmSync(join(runsDir, id), { recursive: true, force: true });
