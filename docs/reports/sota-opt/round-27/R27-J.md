### 2.4 裁决

四腿全部「无候选」，三重收口：

1. **生产剂量微小**：T = 历史级联铸造总量（稀频手工隐私命令的
   累积），现实个位～十位。T=20 现实上界档两轮 min 均**低于**
   T=0（647.6<655.8、588.1<619.0）= 深度亚噪声；幻想档 T=1000 也
   仅 +~100µs/次稀频命令。按 0.19µs/墓碑斜率越两位数 ms 落地线需
   T≈10⁵ 并叠持续删除通量——比 DELINV 的双重幻想更甚（feedback
   墓碑只能由逐 episode 手工删除命令铸造）。
2. **携带响应真实但全是线性字节/解析契约，任何优化形态撞已闭/
   钉死族**：no-match 侧延迟或跳过侧车读 = **S5-J-3 钉死本体**
   （本轮量化其放弃收益：现实 T 亚 µs；fail-open 损坏侧车反例不
   随 T 衰减）；两笔写并行 = **S6-J-1 钉死本体**（复活窗口）；
   解析 Set 跨命令缓存 = X1-1（多进程外部变异侧车）；侧车改增量
   追加日志 / 拆分 = 持久化形态变更（R14-J Cell A/B 判决的数据面
   契约评审域）+ 打破快照原子配对（S6-J-1 同型）；去 sort / 去
   pretty / 改紧凑 = S4-G-6/S6-E-4 磁盘字节面家族（排序规范形即
   审计契约与 W-2 等价性的来源）；跳过 every-string 校验 =
   fail-open（W-9 直证该卫点火）；「假定有序归并」省 sort = 对
   schema 合法乱序侧车 fail-open（读契约不验有序），补验 = 同价
   O(T) 扫描。
3. **幻想档也无池**：写侧 sort+stringify 全额 ~0.4ms 只占 T=5000
