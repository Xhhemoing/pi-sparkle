## 2. 第二十八遍枚举：持久店零态表征面（ZREP，六腿 × 两臂 + 八类见证）→ 全部「无候选」→ 诚实空结果

### 2.1 轴定义与战役首创性（非重铸论证）

**受控变量**：切片持久工件的**空态物理表征**——同一逻辑空态的
两种磁盘形式，在读缝/写缝命中的臂：

- feedback 侧车：**E 臂**（ENOENT，从未物化；
  `readFeedbackTombstoneIds` L19–24 catch ENOENT → "[]"）vs
  **F 臂**（规范空文件 "[]\n" 3 字节）；
- feedback records 日志：**E 臂**（ENOENT，`readJsonlObjects`
  L29–32 catch → ""）vs **Z 臂**（零字节文件，同函数 L33
  raw==="" 早退——两臂在返回值上合流，物理价不同）；
- preferences.json 快照：**E 臂**（`loadFromDisk` L20 existsSync
  卫早退）vs **C 臂**（规范空快照
  `{"observations":[],"tombstones":[]}`——动词可铸：
  configure(path) + clearPreferences()，W-5 字节账户直证铸造形
  与播种形逐位相等）；
- adaptation/feedback **目录**：缺席臂（首次 append 的 mkdir
  真创建）vs 在位臂（mkdir recursive 的 EEXIST 型探针，S7-J-6 /
  R16-J 已定价探针本体）。

**二十七轮从未受控的证据**（逐报告核对）：

- 锚点级联格（R8-J..R27-J 九格矩阵）**从不写侧车** ⇒ 恒在 E 臂；
- R27-J SIDEC 全网格**恒播种侧车文件**（T=0 = 3 字节文件）⇒ 恒在
  F 臂——两个夹具家族各据一臂、从未在同夹具内 A/B；
- R18-J skip 普查对每个 skip 端点只在其夹具实现的单一表征上定价
  （空店级联 19.5–61.1 µs 单带，未分臂）；
- R13-J fs 动词 × API 形态普查的剂量在**代码形态**侧（stat→access
  换形、探针消除、双探针合并），输入状态非变量；
- R14-J / R19-J / R20-J / R26-J / R27-J 的剂量全部是**量级/组成/
  次序**坐标，零的表征从未独立受控。⇒ **战役首创**。

**与已闭轴的区分**：非 SIDEC（T 量级 vs 零的表征，§0）；非 R24-I

**生产通量与臂的可达性**（grep 普查直证）：物化动词恰三个——

### 2.4 裁决

六腿全部「无候选」，三重收口：

1. **生产已坐在便宜臂上，且臂不是自由变量**：E 臂只在首次真实写
   之前存在（§2.1 物化动词普查），是工件生命周期的引导瞬态；
   唯一可想的「优化」——预物化规范空文件以换掉 throw 机器——
   实测为**负优化**（后续每读 +19–26 µs、每 pref 命令水合
   +3.6 µs）且属 adaptation 面无用户动作物化文件的数据面契约
   变更（record-classes 隐私字典 + 状态面评审域）；反向「延迟/
   跳过物化」在生产里已是现状（no-match 不写、configure 不建）。
2. **全部代码侧改形撞已闭族**：探针消除 / stat→access /
   existsSync+read 合并 = R13-J ENOTDIR fail-open 反例族已裁；
   存在位跨命令缓存 = X1-1（多进程外部物化/删除）；侧车读延迟到
   首匹配 = S5-J-3 钉死本体；零字节臂的 raw==="" 早退已在
   jsonl.ts L33（无可再省）；目录探针消除/缓存 = S7-J-6 自愈语义
   收窄族（R16-J 已分类为自愈探针）。
3. **量级**：读缝臂差 19–35 µs/命令 × 稀频命令（级联 = 手工隐私
   命令；水合 = 每 pref 命令一次），且随首次写**自动消失**；
   引导追加税 +21–31 µs 每 state root **一生恰一次**——全部
   once-per-command / once-per-lifetime µs 拒收类，距落地线
   3 个数量级；本面无规模坐标可外推（零的表征没有阶梯）。

按纪律不铸任何 S28-J-\* ID；ZREP 只入本报告、不写 EXCLUSIONS 行
（父代理计划禁令域）。完备性洞已补：两个历史夹具家族各据一臂的
盲区首次受控点火并被见证——洞内没有优化。
