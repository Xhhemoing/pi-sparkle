## §2 新轴：检查点记录结构组成 / 字段在位混合定价（CKMIX，战役首创）

**为什么是新的**：每 run 地板因式分解 floor = Σ 动词计数 × 动词单价
中，计数侧已被 SCHEDWIN（R21-G）关死、单价侧四输入 + 进程环境已被
R16-G…R20-G 关死、终态类已被 TERMCLASS（R22-G）关死——但「单价」的
**测点组成**从未被隔离过：切片最重 CPU 动词 validateCheckpoint 的
253 µs 锚是**组成极小**夹具（D=0、五个 ledger 种群全空、AO=0、无
run/project/pendingApproval 单例），R14-G 规模阶梯在同一混合比下
整体耦合缩放（每节点 5.1–5.6 µs 是**耦合**读数，无法分离小种群的
潜在二次项），R18-G BYTESHAPE 只动字符串字节、R19-G NAMESHAPE 只动
路径。而 RunCheckpoint 携带**十个独立结构种群 + 四类可选单例**
（§0 实读定位），真实生产工件把它们全部填上（本轮真跑普查直接
见证），且该记录每 run 被校验 2·rounds+2 次 + 每交互命令 1 次、被
fsync 写同样次数——组成响应面是地板算术中最后一个未扫的自由度。
R21-G §3 否掉的 EVMIX（事件类构成）与此**不同轴**：那是
validateEvent（负载尺寸免疫 guard）+ 0.29 ms 计算顶封顶的空关轴；
CKMIX 的宿主动词栈**不在**计算顶内（253 µs × ~26 次/run ≈ 6.6 ms
起步，组成极大点更高），且与 durable write 字节面直接耦合。与
R23-A「G×E 自耦合积分」的区分：本轴**不做**跑内增长积分（那是
被禁移植的兄弟轴机制），只做**静态组成响应面**——每个测点是一个
冻结组成的检查点，被反复校验/落盘定价。该轴一次性回答：(a) 十个
种群各自的边际单价与线性性（耦合阶梯藏不住的小种群二次项在隔离
阶梯下无处躲）；(b) 可选单例（run/project/pendingApproval/节点
可选字段）在位与否的价差；(c) 组成极大点对锚点算术的修正量级；
(d) 校验器对被价字段是否真的活着（篡改必须精确抛错，否则是
fail-open 伪装）。
