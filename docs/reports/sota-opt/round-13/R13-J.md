**位点 A：`privacy/deletion.ts` `statExists` 存在性探针形态。**
生产形态 `try { await stat(path); return true } catch { return false }`
（catch-all），被 `deleteRunRecords`（1 次/命令）与
`deleteEpisodeRecords`（2 次/命令）在 `rm` 之前调用；`removedPaths`
输出契约要求知道删除前是否存在。
- **(a1) stat→access 换形**：`access(F_OK)` 同为单 syscall、免
  statbuf 编组，catch-all 语义可完整保留 ⇒ 逐位等价成立。探针实测
  （附录 B，两次独立运行 × 3 rep）：present 侧 delta =
  **+1233/+457/+939ns**（run1）、**+1247/+769/+944ns**（run2）——
  方向稳定但亚 1.3µs；missing 侧 delta = **+529/+434/−294ns**（run1）、
  **+1271/−606/+207ns**（run2）——**符号翻转**。每删除 CLI 命令
  ≤2 次探针，合计亚 3µs，距落地线 4 个数量级；且删除命令被级联地板
  613.7–723.8µs（S0c）与 rm 本体（~60µs/文件）支配。
  裁决：**once-per-command µs 类换名不铸 ID**（S12-D-1 同类判据 +
  S4-J-3 删除数据面强调区）。
- **(a2) 探针消除**：无 force 单 `rm`/`unlink`，以 ENOENT 抛错判
  「原本不存在」，把 2 syscall 收敛为 1。快乐路径实测省
  **36.8–39.3µs/文件**（run1）、**35.4–40.2µs/文件**（run2）——
  但**理论不成立**：确定性反例（附录 B，两次运行均复现）——构造
  父路径组件为普通文件的病态路径，生产 catch-all 探针捕获 ENOTDIR →
  false → 跳过 rm → 命令**成功**返回空 removedPaths；消除形态把
  ENOTDIR 抛出删除动词——**fail-open→fail-closed 错误面翻转**
  （R5-J §3 错误面契约家族：与级联 records 读 `.catch(() => [])`
  同域）。更强的结构论证：双调用形态区分「探针失败（任何原因）→
  静默跳过」与「探针成功后删除失败 → 上抛」两类错误处置，单调用
  形态从一个错误码原理上无法判别该错误应归哪类（EACCES 两侧同码）
  ⇒ 无健全的单调用等价形态存在。另 `deleteRunRecords` 的目录情形
  unlink 不适用，需 rm(recursive) 无 force 变体，同反例同判。
  裁决：**理论失败 + 闭家族（R5-J 错误面 + S4-J-3 删除数据面 µs 类），
  不铸 ID**。

**位点 B：`preferences/store.ts` `loadFromDisk` 双探针载入。**
生产形态 `if (!existsSync(persistFile)) return;` 后
`readFileSync(persistFile)`——existsSync 对**任何** stat 错误返回
false（静默跳过载入），stat 成功后 readFileSync 的错误（含 JSON.parse

- **理论不成立**：确定性反例（附录 B，两次运行均复现）——父路径
  组件为普通文件时 existsSync → false → 生产**静默跳过**；单读形态
  catch 只认 ENOENT ⇒ ENOTDIR 从
  `configurePreferencePersistence` 抛出——同款 fail-open→fail-closed
  翻转。且与位点 A 同构：合并后无法区分「stat 会失败（→跳过）」与

## 附录 B：两处从未点名探针位点的裁决探针（完整，可复现）

```ts
/**
 * R13-J fs-verb x API-form census probes (loser adjudication; not committed).
 * Site A: privacy/deletion.ts statExists (stat, catch-all -> false) vs
 *         (a1) access(F_OK) form and (a2) probe-elision (unconditional rm,
 *         detect prior existence from the throw). a2 carries a deterministic
 *         error-surface counterexample (ENOTDIR path component).
 * Site B: preferences/store.ts loadFromDisk existsSync+readFileSync double
 *         probe vs single readFileSync catch-ENOENT. Deterministic
 *         error-surface counterexample (ENOTDIR path component).
 * Deterministic fixtures; three timed reps each; equivalence / divergence
 * asserted inline.
 */
import { access, mkdir, rm, stat, unlink, writeFile } from "node:fs/promises";
import { existsSync, mkdirSync, readFileSync, rmSync, writeFileSync } from "node:fs";
import { mkdtempSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";

const hr = (): bigint => process.hrtime.bigint();
const us = (a: bigint, b: bigint, n: number): number => Number(b - a) / 1000 / n;

// ---- Site A: existence-probe forms on the deletion path
async function statExistsProd(path: string): Promise<boolean> {
  // mirrors privacy/deletion.ts statExists L41-48
  try {
    await stat(path);
    return true;
  } catch {
    return false;
  }
}
async function accessExists(path: string): Promise<boolean> {
  try {
    await access(path);
    return true;
  } catch {
    return false;
  }
}
/** probe-elision form: single rm without force; existence inferred from throw. */
async function rmDetect(path: string): Promise<boolean> {
  try {
    await unlink(path);
    return true;
  } catch (error: unknown) {
    const code =
      error !== null && typeof error === "object" && "code" in error ? error.code : undefined;
    if (code === "ENOENT") return false;
    throw error; // <-- error-surface divergence lives here
  }
}

async function siteA(): Promise<void> {
  const dir = mkdtempSync(join(tmpdir(), "r13j-probeA-"));
  const present = join(dir, "present.jsonl");
  const missing = join(dir, "missing.jsonl");
  await writeFile(present, "x\n", "utf8");

  // equivalence: stat-form and access-form agree on present/missing
  if ((await statExistsProd(present)) !== true) throw new Error("A: stat present");
  if ((await accessExists(present)) !== true) throw new Error("A: access present");
  if ((await statExistsProd(missing)) !== false) throw new Error("A: stat missing");
  if ((await accessExists(missing)) !== false) throw new Error("A: access missing");

  // error-surface counterexample for probe-elision (a2): a path whose parent
  // component is a regular file. statExists catches ENOTDIR -> false -> the
  // production delete SKIPS rm and SUCCEEDS with empty removedPaths. The
  // elided form throws ENOTDIR out of the delete verb: fail-open -> fail-closed flip.
  const fileAsDir = join(dir, "notadir");
  await writeFile(fileAsDir, "file\n", "utf8");
  const pathological = join(fileAsDir, "child.jsonl");
  if ((await statExistsProd(pathological)) !== false) throw new Error("A: prod should treat ENOTDIR as absent");
  let elidedThrew: string | undefined;
  try {
    await rmDetect(pathological);
  } catch (error: unknown) {
    elidedThrew =
      error !== null && typeof error === "object" && "code" in error ? String(error.code) : "?";
  }
  if (elidedThrew !== "ENOTDIR") throw new Error(`A: expected ENOTDIR from elided form, got ${elidedThrew}`);
  console.log("site A: probe-elision divergence confirmed (prod=silent-skip, elided=ENOTDIR throw)");

  // timing: stat vs access on present + missing (pure probe swap upper bound)
  const N = 5000;
  for (let rep = 0; rep < 3; rep++) {
    let t0 = hr();

function loadProd(persistFile: string): string | undefined {
  // mirrors preferences/store.ts loadFromDisk L20-21 probe shape
  if (!existsSync(persistFile)) return undefined;
  return readFileSync(persistFile, "utf8");
}
function loadSingle(persistFile: string): string | undefined {
  try {
    return readFileSync(persistFile, "utf8");
  } catch (error: unknown) {
    const code =
      error !== null && typeof error === "object" && "code" in error ? error.code : undefined;
    if (code === "ENOENT") return undefined;
    throw error; // <-- error-surface divergence lives here
  }
}
```
