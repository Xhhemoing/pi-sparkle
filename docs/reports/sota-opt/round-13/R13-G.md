### §3.2 新轴实扫：Node 22.22 API 面（本轮真实新增的机制维度探测）

R8–R12 的机制轴均为代码结构机制；本轮补扫**运行时 API 面**——即

   （惰性 import，生产收益恒 0）。**命中，不重开。**
2. **`fs.promises.writeFile(path, data, { flush: true })` 换
   writeAtomic 手工 `handle.sync()`**——系统调用序列逐一相同
   （open/write/fsync/close），收益恒 0；且该面是 S9-G-3 硬禁的
