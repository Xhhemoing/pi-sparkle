## 结论

**落地 1 项（S5-C）逐位保行为优化**，位于 `lin-alg.ts` 的 `solveSymmetric`
消元内核：**内层 k 循环按 4 展开（顺序体 + 顺序余数）**。重剖析（V8
`--cpu-prof`，同一 Iter2 夹具 rows=400/p=60/bootstrap=200）确认 S4-C 后
成本模型未再翻转——`solveSymmetric` 自身仍占 **64.9%**（~700 ms/报告），
每报告 8966 次 solve（全部 n=60）共 **643,729,878 次**消元内层迭代。S4-C
已把每迭代内存访问压到最简（2 装载 + 乘 + 减 + 1 存储），浮点运算序列被
X2-3 锁定，边界检查不受 JS 控制——剩余可削减的非浮点成本只剩**每元素一次
的循环控制（自增/比较/分支）**，而 V8 不自行展开该循环（实测 1.3× 直接
证明）。按 4 展开且循环体严格保持 k, k+1, k+2, k+3 的源序执行、余数循环
顺序收尾，指令级序列与滚动循环逐条相同——装载、浮点运算、存储的集合、
值与顺序零改变，逐位等价由构造成立，**且所需前提比 S4-C 更弱**（S4-C 需
"提升点后无语句重赋值 m[col]/m[row]/x[col]"的别名论证；顺序展开不重排
任何操作，无 break/continue 的计数循环展开无需任何别名分析）。每报告
消除约 **4.4 亿次**内层循环控制三元组。落地前独立干净两路基准三次
**+316.0 / +292.6 / +273.9 ms（1.35–1.40×）**，落地后冻结 S4-C 对照 vs
生产导入三次 **1082.0→807.3 / 1034.3→804.8 / 1067.0→800.8 ms
（1.29–1.34×，省 229.5–274.7 ms）**——远超 ±35 ms 噪声带，量级为本切片
五轮第二（仅次于 S4-C 的 613 ms）。**28,555 项逐位一致性检查 × 3 次独立
运行全绿**，含 75 个直接内核对抗矩阵（225 次主元交换、奇异、NaN/∞、±0、
factor=0 跳过、n=0/1、非方阵抛错；随机 n=2..12 扫过展开主体/余数的全部
切分）。同族七个变体（U2/U8/RP2/RP4/RP2U2/RP4U2 + 后代组合）按单赢家
裁决淘汰记入排除表（S5-C-1..4），另有三个理论裁决淘汰项（S5-C-5..7）。

这推翻了 R4-C 收口声明中「S4-C 后消元/回代内层循环每次迭代只剩浮点运算
本体」的一处过强概括：每次迭代还剩**每元素一次的循环控制开销**——它既不是

## 1. 重剖析：S4-C 后成本模型核实（未翻转）

R4-C 落地后的首要问题是成本模型是否又变。本轮 V8 CPU profile（perf 夹具
warmup 后 5 次重复，总采样 6651 ms，Node 22.22.2）：

| 函数（自身时间） | 占比 | 折合 /报告 |
| --- | --- | --- |
| `solveSymmetric`（lin-alg） | **64.9%** | ~700 ms |
| `irls` 自身（eta 去重点积 + 累加 + fill） | 21.1% | ~228 ms |
| `sigmoid` | 2.9% | ~31 ms |
| `fitLogitAdditive` 自身 | 2.8% | ~30 ms |
| lin-alg 匿名回调（防御拷贝） | 1.9% | ~20 ms |
| `averagePredictiveComparison` | 1.8% | ~19 ms |
| GC | 0.8% | ~9 ms |

与 R4-C 落地后剖面（63.7%/22.8%）一致——主导成本仍在消元内核。内核形态
插桩（同夹具）：8966 次 solve 全部 n=60；消元行步 15.87M 次，其中
factor===0 跳过仅 49,333 次（0.3%）；消元内层迭代 **643,729,878 次/报告**
（k 循环平均行程 ~40.7）；主元交换 0 次（生产分布对角占优——交换路径必须
靠对抗矩阵覆盖，见 §2.4）。

S4-C 后的内层循环体为 `rowArr[k] = rowArr[k]! - factor * colArr[k]!`：
2 次元素装载 + 乘 + 减 + 1 次存储 + 2 次边界检查 + **每元素一次的
自增/比较/分支**。前四类分别被 X2-3（浮点）、S4-C（冗余外层装载已消除）、
V8（边界检查非 JS 可控）、S4-C-2（表示变换实测更慢）覆盖；唯一未被任何
既有 ID 命名的可削减成本是最后一类——循环控制。

## 2. 落地项 S5-C：消元内层 k 循环按 4 顺序展开

### 2.1 机会与理论

计数循环每元素支付一次自增/比较/分支；行程 ~40.7 时 V8 不自行展开
（TurboFan 不做通用循环展开）。按 4 展开：主体每轮执行 k, k+1, k+2, k+3
四个体后 k+=4，余数循环从当前 k 顺序收尾——每 4 元素只付一次循环控制，
每报告循环控制三元组从 ~643.7M 次降到 ~200M 次（主体 ~161M + 余数
~23.7M + 每次进入的常数），消除约 **4.4 亿次/报告**。浮点运算数、边界
检查数、内存访问数零变化。

### 2.2 保行为论证（逐位）

- **顺序展开是恒等变换**：无 break/continue 的计数循环，主体按源序执行
  k, k+1, k+2, k+3，余数循环顺序收尾且主体条件 `k < n - 3` 保证不越界、
  不重复、不遗漏任何一个 k——执行的指令序列与滚动循环**逐条相同**（同一
  装载序、同一浮点运算序、同一存储序）。不需要 S4-C 式的"无重赋值"别名
  论证（没有任何操作被重排），更不需要数值引理。n<4 的行程完全落入余数
  循环，与滚动循环逐字同路径。
- **两把既有锁均未触碰**：X2-3 锁"改变浮点结果的数值路径变更"——本项
  浮点运算序列逐字保留；"防御性拷贝=公开 readonly 契约本体"——拷贝语句
  原文保留（S4-C-3 维持）。S4-C-1 之死存储跳过未重提（k 仍从 col 起）；
  S4-C-2 之表示变换未重提（仍为 number[][] 行数组）。
- **对抗域直接实证**（fit 级夹具无法强制的路径）：75 个内核矩阵 ×
  {production, U4, U2, U8, RP2, RP4, RP2U2, RP4U2} vs 冻结 `6b997f1`
  参考，元素级 `Object.is`——含强制主元交换的 SPD 与非对称矩阵（共 225
  次交换）、奇异/全零 → null、NaN/∞ 传播 → null、±0 条目、factor=0
  跳过、n=0/n=1、非方阵/长度不匹配 → 同名同消息 DomainValidationError；
  随机 n=2..12 扫过展开主体/余数的全部切分（行程 1..12）。
- 无跨调用状态；PRNG 调用序、IRLS 迭代数、beta 轨迹全部逐位不变（52 个
  fit 级夹具实证）。

### 2.3 相似方案组：单赢家裁决

同族「消元内核循环控制重构」按机制分组。多路进程内赛马使参数化 solve
调用点超多态（对照通胀），故**淘汰赛只取同环境相对序，落地依据为干净
两路独立进程**（7 次交错重复取中位 × 3 次独立运行）：

| 变体 | 机制 | 裁决 |
| --- | --- | --- |
| VAR-U4 k 循环按 4 顺序展开 | 纯循环控制重构，全局操作序逐条不变 | **落地 S5-C**：干净两路 +316.0/+292.6/+273.9 ms（1.35–1.40×）；落地后对照生产导入 +274.7/+229.5/+266.2 ms（1.29–1.34×），六次运行方向一致 |
| VAR-U2 按 2 展开 | 同 | 淘汰 S5-C-1：被 U4 支配——多路赛马 +137.6 vs U4 的 +244.5 ms；仿真内 886–913 vs U4 812–816 ms |
| VAR-U8 按 8 展开 | 同 | 淘汰 S5-C-2：对 U4 决斗 +9.4/+14.9 ms，低于 ±35 ms 噪声带——体积翻倍换亚噪声增益，审计面劣于 U4（R4-C H3/S3-C-1 同款裁决） |
| VAR-RP2 行对分块（2 行共享 colArr[k] 装载） | 全局操作序改变；每内存位置的读写序与值不变（行数组互异、colArr 只读、x 槽互斥） | 淘汰 S5-C-3：多路赛马实测**慢于滚动对照**（−108.7 ms）；仿真内 991–1006 ms 亦全面劣于 U 族 |
| VAR-RP4 行四分块 | 同 RP2（共享装载 ×4） | 淘汰 S5-C-4：对 U4 决斗 +20.3/+20.4/+25.2 ms 三次同向但**全部低于噪声带**，且等价论证需"行互异 + 只读列 + x 槽互斥"三元引理、配对/回退结构 ~30 行——按 S4-C-1 先例（同向亚噪声 + 额外引理 = 不落地）淘汰 |
| VAR-RP2U2 / VAR-RP4U2 分块+展开组合 | 同上叠加 | 并入 S5-C-3/4：RP2U2 被支配（多路 +180.9）；RP4U2 对 U4 决斗 −4.1/−0.1 ms 持平——寄存器压力吞掉共享装载的理论收益 |
