热循环（X′WX / X′Wz）：**按支撑大小分派到直线化循环体（s=2..5 各一个

存储落在与滚动循环完全相同的内存位置、以完全相同的顺序发生——被消去的

## 2. 落地项 S6-C：累加循环按支撑大小直线化分派

### 2.1 机会与理论

短循环的每元素成本中循环控制与索引读取占比最高，且 V8 对行程 2..5 的
计数循环既不展开也不特化。`switch (active.length)` 分派到 s=2..5 的
直线体后：循环控制三元组 88.9M → 0（代之以 3.59M 次分派）、`active`
元素读取 88.9M → 15.97M（每行每索引恰读一次，提升为局部量）；浮点
运算数、访存目标与顺序、边界检查语义零变化。s=1（截距-only 设计，
生产可达）与任何 s>5（生产不可达，防御性保留）走 default 的逐字滚动
循环。

### 2.2 保行为论证（逐位）

- **直线化是恒等变换**：case s 体按源序执行 ai=0..s−1，每个 ai 内先
  `xtwz[a_ai] += wz`、再取行引用、再按 bi=0..s−1 升序执行 s 次
  `+w`——与滚动循环的指令序**逐条相同**（同一浮点装载序、同一加法序、
  同一存储序）。无 break/continue、无重排、无遗漏。
- **索引读取提升不可观察**：`active` 在 fit 全程只读（supports 每基线
  拟合构造一次，无写入者）；`xtwx` 行与 `xtwz` 均为 irls 内新分配，
  与任何支撑数组不可能别名——把 `active[0..s−1]` 提升为整数局部量只
  改变对一个不变整数数组的读取次数，不触任何浮点。
- **既有锁均未触碰**：加法项集合/值/顺序零改变（X2-1、R2-C 批量累加
  之外）；无浮点路径变更（X2-3 之外）；无串行链重排（S5-C-5 之外）；
  两层循环未融合、无 per-key 去重（S3-C-2 之外）；对称单元仍全量累加
  （S3-C-1 之外）；`fill(0)` 原文（S5-C-7 之外）。
- **对抗域直接实证**（报告级夹具无法强制的路径）：24 个直接 irls 夹具
  ×｛SW、SW45、SW5、ISW、BU4、BU2、LEN｝vs 冻结 `9d5e760` irls，
  coefficients 元素级 `Object.is`、null 对 null——支撑大小 **1..8 全扫**
  （6..8 钉死 default 臂对超界输入与滚动循环逐位一致）、~1/3 行共享
  向量引用与规范键（压测 eta/mu 去重 + 分派共存）、maxIter∈{1,3,50}。
- 无跨调用状态；PRNG 调用序、IRLS 迭代数、beta 轨迹全部逐位不变
  （53 个全报告夹具实证，含 bootstrap=200 默认档）。

  落地量吻合。

### 2.5 渐近收口（逐项对锁）

S6-C 后两大热点的每元素/每行成本完全枚举如下，每项标注锁定者：

- **solveSymmetric 消元内层每元素**：2 浮点装载 + 乘 + 减 + 存储
  （X2-3 + S4-C）、2 边界检查（V8 无 JS 级消除手段，S4-C-2 实证表示
  变换更慢）、1/4 循环控制（S5-C；更深展开 S5-C-2、行分块 S5-C-3/4）。
  主元搜索 S5-C-6、回代 S5-C-5、防御拷贝=公开契约（S4-C-3）、
  `stop`/校验残留微观 S6-C-7（个位 ms 上界）。
- **irls 每行访问**：w/z/wz 三次浮点（公式本体）+ 1 次 switch 分派
  （机制不可再减——按大小排序行以消除分派会改累加顺序，违逐位）+ s 次
  支撑索引装载（已是每索引一次的下界）+ s²+s 次浮点加法与配套装载/
  存储（**即被逐位契约锁定的求和项本体**；批量化 R2-C 裁决违结合律；
  上三角减半 S3-C-1 实证被镜像抵消）。
- **irls 每迭代其余**：eta 去重 Ω(distinct keys × p) 点积串行链
  （S2-C 下界 + X2-1 + S5-C-5）、O(p²) 归零 memset（S5-C-7，~15-25 ms
  上界）、eta/mu 拷贝戳循环（S6-C-6，~2-4 ms 上界）、delta/收敛判据
  （S2-C-3）。
- **每 fit 其余**：APC 四面锁（X2-2/S1-C-1/S2-C-2/S2-C-4，自身 ~21
  ms）、on-prob S2-C-1、bootstrap 抽样 Ω(draws×rows) 受 PRNG 调用序
  锁定（S3-C-3 缓冲复用抖动）、sigmoid 数值路径（X1-3/X2-3）。

与前五轮收口的区别：**本轮枚举做到了每项都有具体 ID 或公开契约对锁，
且未锁定项（S6-C-6/7）上界合计 <15 ms、低于噪声带**。前五轮的推翻
均源于某类成本未被枚举（重复构建→S1-C、重复求值→S2-C、恒等乘法→
S3-C、冗余装载→S4-C、长循环控制→S5-C、短循环控制+索引重读→S6-C）；
本轮在两大热点上按「装载/浮点/存储/边界检查/循环控制/分派/索引读取」
七类完全分解后，不再存在未命名的类。该声明仍仅限当前变换类知识——
推翻它需要先指出一个不在上述七类中的成本类别。
